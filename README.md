# dsh-her

**DSH 桌面女友，[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）插件。** 她可以住在你真正的桌面上（浮在所有窗口上面，或者住在壁纸里），也可以住在 dsh 的网页里，能语音聊天、会先开口、记得你。桌面程序支持 macOS（Apple 芯片）和 Windows；Linux、VPS 和手机上她住在网页里，见 [VPS 部署](https://github.com/AIcivilization/dsh-her/blob/main/docs/VPS部署.md)。

## 安装

在 dsh 桌面版的插件页搜 `dsh-her` 安装；也可以把 [这段话](https://github.com/AIcivilization/dsh-her/blob/main/docs/AI帮你装.md) 发给 dsh 里的 AI，让它帮你装。装好后点 dsh 左侧的"她"，跟着向导走几步就好。

## 怎么和她说话

- **对话小条**：按 **⌃⌥↩**（Windows：**Ctrl+Alt+Enter**）、双击她，或点 dsh 对话框上她的小头像，弹出小条：能打字，也能按住话筒说话；全屏时也能叫出来。所有对话都存在 dsh 左侧的"她"工作区里，可以新开一段，也可以接着之前那段。
- **说话**：按 **⌃⌥空格**（Windows：**Ctrl+Alt+空格**）说一句，说完自动发出；她说话时你开口就能打断她。鼠标移到她身上，脚边会出现话筒（按住说）和键盘（打开小条）两个按钮。菜单里可以勾"一直在听"；在「说话和聆听」里可以打开"任何程序里按住右边的 Option（Windows：右 Alt）说话"。
- **她在哪儿回答**：你用说的，她在头顶的气泡里回答（同时出声）；小条开着时，对话都在小条里，头顶不重复显示。
- **她会先开口**：你回到电脑前、有日子的事快到了、很久没说话时，她会自己说一句。每天最多 3 次，23:30 到 8:30 不打扰，你不回她就慢慢少说；开会时用右键菜单的"专注一会儿"。在「她」页面 → 主动说话 里调。
- **碰她**：点她的头或身体，她马上有反应，隔一会儿还会说一句符合性格的话；按住不动是摸摸头。
- 在 dsh 里打开"她 · 名字"会话直接打字，或在任意会话里用 `/her 想说的话`：她都会在桌面上回答。
- 在她身上按住可以拖动；右键她（或点菜单栏的"她"）可以勾"浮在桌面上""住在壁纸里"、打开设置，或退出。
- **关掉她**：「她」页面右上角的"⏻ 关掉她"（或右键菜单）：桌面上、网页里都收起来，不听、不说话、不先开口，重启后也还关着；点"叫她出来"回来。

## 设置

都在 dsh 左侧的「她」页面里。顶上是她的名片和开关，左边一列分四组：

- **总览**：一张她现在的样子（真的桌面、桌宠、头像，每样都有一条线指着说明，点了去设置），图下面一排"她出现在哪儿"的开关，再往下是她的三视图、几个顺手的开关、现在的设置。
- **她**：人设（可以粘贴人设卡）、声音、记忆。
- **外观**：形象、编排、素材库、素材指南、皮肤、形象工坊。
- **相处**：说话和聆听、主动说话、对话。
- **系统**：模型、住在哪儿、外接语音、关于。

## 多个人物

「人设」页顶上有一排人物卡：可以设好几个不同的她，点谁就换成谁。每个人物有自己的人设、声音、模型、形象和编排、记忆和对话；素材库、皮肤、外接语音是共用的。

## 她出现在哪儿

「总览」那张图下面有一排开关：**壁纸里**（场景在所有窗口后面）、**桌面上**（桌宠）、**dsh中**、**dsh对话框上**（小头像）、**菜单栏图标**。开了哪个，上面的图里和你的屏幕上那里就有她；关了就没有。壁纸和桌面上可以同时开。她在网页里作背景时，可以调遮罩和朦胧，让字更清楚。

## 编排、皮肤和开机动画

- **编排**（「她」页面 → 编排）：一行一类东西（皮肤、头像、桌面、宠物），一列一个场景；格子里放素材库里的图片和视频，选几个就轮换或随机。场景什么时候出现由你定：说话时、被碰、时间段、你在不在、隔一会儿随机，或者让她自己选（比如聊到麻将，她自己去"打麻将"）。打开"让她按这份编排来"才生效。
- **素材库**：传图片、视频、SVG，一次可以传一整个文件夹；每个文件都会对照规格看一遍，不合适的地方标出来。绿幕（或别的纯色底）的图和视频可以点"抠掉背景"变成透明的。
- **素材指南**：要做哪些图和视频、多大、有什么要求，每一样都有可以直接复制的提示词；先做定妆照和三视图，其余都从三视图派生。同一份内容见 [素材规格与提示词](https://github.com/AIcivilization/dsh-her/blob/main/docs/素材规格与提示词.md)。
- **皮肤**（「她」页面 → 皮肤）：换整个 dsh 的颜色、背景图、字体和她的对话小条；自带鲸鱼蓝、深海夜，也可以传自己做的。**开机动画**：她出场时播一段。
- **+AI**：编排、皮肤、SVG 旁边的"+AI"打开一段设计对话，说"把衣服换成墨绿色"就改；改坏了能退回。你也可以直接让她换皮肤。
- **外接语音**（「她」页面 → 外接语音）：讯飞、OpenAI 兼容的服务、自己的 GPT-SoVITS，或者别的 dsh 插件提供的声音和识别。

## 形象

一个形象可以有好几个场景（窗边、书桌、卧室……），按时间和你在不在自动换，也可以跟她说"去卧室吧"。你可以选现成的形象，也可以用自己做的图和视频：用编排的话看 [素材规格与提示词](https://github.com/AIcivilization/dsh-her/blob/main/docs/素材规格与提示词.md)；想整套导入成一个形象，看 [形象工坊的素材说明](https://github.com/AIcivilization/dsh-her/blob/main/docs/素材生成提示词.md)。

## 声音

默认用微软 Edge 的声音，免费，要联网。也可以在「她」页面里换成阿里云百炼的声音（要你自己的 key），或者在 Mac 上用本机的声音。

## 她记得的事

她会自己记、自己查，每天整理一次写日记。在「她」页面里可以看、确认、删掉；也可以用 `/her 记忆` 查看、`/her 忘掉 f3` 删除、`/her 导出记忆` 导出，或者直接跟她说"把那件事忘掉"。文件都在你自己电脑上的 `~/.dsh-her/characters/<角色>/memory/`。

## 隐私

不收集任何使用数据。她的记忆、设置都存在你自己的电脑上。桌面程序只连本机 `127.0.0.1`，需要令牌（`<home>/token`，权限 600）。百炼的 API key 不写进文件：Mac 上存在系统钥匙串里，其他系统用环境变量 `DASHSCOPE_API_KEY`。

## 她能做什么

- 🏠 **住在哪儿都行**：壁纸里、桌面上、dsh 网页里；手机打开 dsh 网页也能找到她。
- 🎙️ **语音聊天**：按一下快捷键说话，说完自动发出；她说话时你开口就能打断她。
- 💬 **会先开口**：你回到电脑前、有事快到了，她会主动说一句。不吵，夜里不打扰。
- 🫧 **碰她有反应**：点她马上有动作，按住是摸摸头。
- 📒 **记得你**：你说过的事她记得，只存在你自己的电脑上。
- 🎭 **好几个角色**：各有人设、声音和形象，粘贴一张人设卡就能开始。
- 🎨 **样子随你换**：六套初始模版和素材指南；皮肤、开机动画、别人做的设计包都能装。
- 👾 **像素表情**：把照片、视频（绿幕也能抠干净）变成会动的像素画，导出 GIF 发微信当表情；也能掷骰子、跟 AI 说一句话来做，当开机动画或 dsh 对话背景。

## 安装

在 dsh 的插件页搜 `dsh-her` 安装，再点 dsh 左侧的"她"，跟着向导走几步。

- **dsh 版**：她住在 dsh 网页里。
- **dsh + 桌面版**（Mac、Windows 上默认）：再加一个桌面程序，她能浮在桌面上、住进壁纸里。dsh 启动后自己下载安装，Mac 约 150 MB，Windows 约 210 MB。只想要 dsh 版，在「她」页面点"只要 dsh 版"。

说话：**⌃⌥空格**（Windows：Ctrl+Alt+空格）；打开对话小条：**⌃⌥↩**（Windows：Ctrl+Alt+Enter）。

## 隐私

不收集任何使用数据。记忆和设置都存在你自己的电脑上，API key 存在系统钥匙串里。

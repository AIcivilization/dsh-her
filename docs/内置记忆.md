# 内置记忆（P1）

> 已定：灵魂引擎（dsh-vael）先不接。P1 用 dsh-her 内置的简单实现；接口按"以后可以整个替换"来设计。

---

## 1. 记什么

| 层 | 内容 | 存在哪 | 怎么用 |
|---|---|---|---|
| **关于你** | 你的称呼、生日、喜好、忌讳、重要的人和事 | `profile.json`（结构化，可编辑） | **每轮都放进系统提示词**，控制在 300 字以内 |
| **她的日记** | 每天一篇，她写的"今天和你发生了什么" | `diary/2026-10-28.md` | 最近两天的摘要放进系统提示词；更早的通过 `recall` 查 |
| **事件** | 值得以后提起的具体事情（"你说下周三面试"） | `episodes.jsonl`（时间、内容、标签、提到的日期） | 用 `recall` 查；带日期的事到时候会主动提起 |

存放位置：`~/.dsh-her/characters/<cid>/memory/`。全是本地文件，可以用文本编辑器直接打开。

完整的对话记录仍在 dsh 的会话里。会话被压缩后会丢细节，但上面这三层不会丢。

---

## 2. 怎么写入

1. **当场记**：她觉得重要时调用 `remember(内容, 类型)`；你说"记住……"时也会走这条路。提示词要求她在你说到自己的事（称呼、喜好、工作和生活、重要的人、带日期的安排）时就记。
2. **聊完马上过一遍**（2026-10-30 加）：你停下来一分钟、她也说完了，大脑把这几轮新的对话交给模型，挑出关于你的新事实（作为候选）和事件，马上出现在"她记得的事"里。日记不在这一步写。
3. **每天整理一次**：你一段时间没说话（默认 30 分钟）或者到了深夜，从 dsh 会话里读出今天的对话，交给模型整理成：
   - 一篇日记
   - 若干条"关于你"的候选事实
   - 若干条事件
4. **候选事实先给你看**：设置页里显示"她新记住的 3 件事"，可以确认或删除。默认 7 天后自动确认。涉及健康、财务、他人隐私的内容**不会自动确认**。

---

## 3. 怎么回忆

- `recall(问题)`：在日记和事件里做关键词检索，结合时间远近打分，返回最相关的几条。
  - P1 **不用向量检索**。DeepSeek 没有 embedding 接口，额外下载 embedding 模型又会变重。
  - 中文按二字词切分，加 BM25 打分就够用。
- 带日期的事件到期前后，会作为"现场信息"注入，让她自然地提起："今天面试怎么样？"

---

## 4. 你能管住她记了什么

- dsh 的"她"页面 → "她记得的事"：分成"关于你 / 事件 / 日记"，最新的在最上面，今天记下的标"今天"；候选可以确认，每条都能删。
- 桌面上右键她（或托盘菜单）→"她记得的事…"：一个小窗口，同样能看、确认、删除；"人设…"可以直接改名字、称呼和人设。
- 语音"忘掉这件事"：先 `recall` 找到相关条目，向你确认后删除。
- 一键导出（Markdown），一键清空。清空需要二次确认。

---

## 5. 接口（以后换成灵魂引擎时整体替换）

```ts
interface MemoryProvider {
  profile(cid: string): Promise<string>                   // 放进系统提示词的"关于你"
  recent(cid: string): Promise<string>                    // 最近两天的日记摘要
  remember(cid: string, item: MemoryItem): Promise<void>
  recall(cid: string, query: string, limit?: number): Promise<MemoryHit[]>
  digest(cid: string, day: string, transcript: Turn[]): Promise<DigestResult>   // 每天整理
  due(cid: string, now: Date): Promise<MemoryHit[]>       // 到期该提起的事
  list / update / remove / export / clear                 // 给设置页用
}
```

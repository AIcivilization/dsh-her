# 设计：网页身体，让她住在 dsh 的界面里（2026-11-01，第 1、2 步已做，第 3 步还差 VPS 实测）

> 研究了 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)（MIT，4391 星）。§6 三件事已定（按建议）；进度见 §7。

## 1. 那个项目给我们的启发

它把壁纸、吉祥物直接画在 **DSH 的网页界面里**，不开任何桌面程序。所以它有几个我们没有的好处：
- 一个包就覆盖 Windows、macOS、Linux；
- 只要能打开 dsh 的网页，就能用，不需要桌面环境。

我们现在的"身体"是 Electron 桌面程序：
- VPS 没有桌面，用不了；
- Linux 没有包；
- 手机浏览器也用不了。

**好消息是我们离它不远。** 身体的画面层（`body/renderer/`：播放器、动作编排、说话、字幕、麦克风，共约 1400 行）已经只通过一个接口 `window.her`（`HerBridge`）和外面打交道。给这个接口写一个浏览器版，同一套代码就能在 dsh 的网页里跑。

## 2. 目标：两种身体，同一个大脑

| | 桌面身体（现在的） | 网页身体（新的） |
|---|---|---|
| 她在哪 | 真桌面：最上层或壁纸里 | dsh 网页里：浮在界面上，或者当聊天背景 |
| 适合 | 自己的 Mac、Windows | VPS、Linux、手机、不想多装程序的人 |
| 要安装 | 150–220 MB | 不用装，插件自带 |
| 关掉网页 | 她还在 | 她也不在了（大脑还在跑） |

**怎么选**（2026-11-01 改：两种身体地位相同，用户选哪个，哪个就是主要身体）：
- dsh 跑在没有桌面程序的系统上（Linux）：只有网页身体，不提安装；
- 网页是从别的设备打开的（core/where.ts，比如用手机开 VPS 的 dsh）：不管 dsh 跑在什么系统上，都只有网页身体。"下载安装"会装到跑 dsh 的那台电脑上，不是眼前这台，所以不提供；
- 在跑 dsh 的电脑上打开：两个都给；
- 同一台电脑上两个同时开时：桌面身体连着，网页身体藏起来，不重复出声。

## 3. 怎么做

**画面**：`body/renderer` 里和 Electron 无关的部分直接打包进插件的页面代码，配一个 `WebBridge`。

**放在哪**（设置里选）：
1. **浮动小窗**（默认）：角落里一个能拖动、能调大小的她，透明背景的外形（桌宠）直接浮着；点她可以说话。
2. **聊天背景**：场景外形铺在聊天后面，文字浮在上面，和那个壁纸插件一样。
3. **「她」页面里的舞台**：全屏，适合手机。

**出现在每个页面**：`package.json` 的 `dsh.client` 加 `immediately: true`，打开 dsh 就加载，不用先点进「她」页面。

**和大脑怎么连**：现在桌面身体走本机 `127.0.0.1` 上的 WebSocket，远程浏览器连不到。网页身体走 dsh 自己已经登录的同一个地址：
- 大脑发给身体：一条长连接（SSE）；
- 身体发给大脑：普通 POST；
- 声音：按编号另外下载（wav / mp3）。

大脑那边把它当成又一个 `body` 连接，原来的说话、打断、表演逻辑都不用改。

**外形从哪来**：这是**改动最大的一块**。现在外形的列表、加载、导入都在身体程序里（`body/main/pack/`），要挪到两边共用，大脑自己也能做：
- 视频按 Range 方式提供（`<video>` 要能拖动和分段加载），带缓存；
- 选文件夹的系统窗口在 VPS 上没有，换成**从浏览器上传**（素材打成 zip，或者形象工坊项目整包），要有进度条；
- 导入要 ffmpeg：VPS 上用 PATH 里的，没有就下载一个校验过的静态版（和 Windows 版一样的 BtbN LGPL 版）；
- 「框人物区」现在是身体的窗口，也要搬到页面里。

**声音和麦克风**：
- 合成在大脑（VPS）上，浏览器只负责播：Edge、百炼都能用。uv 要加上 Linux 版。本机 Ming 要等 audio.cpp，而且 VPS 没显卡会慢。
- 浏览器不让网页自动出声：第一次要点一下"开启声音"。
- 麦克风：浏览器只在 HTTPS 或 localhost 下才给用。VPS 走 HTTP 时打字仍然能用，页面上说明怎么开 HTTPS。识别在大脑上做（sherpa-onnx 有 Linux 版），浏览器把录音发过去。

**流量**：VPS 到浏览器要走公网，1080p 片段不小。
- 视频长期缓存（带 ETag），只下一次；
- 用到时才下，提前加载下一段；
- 选配"省流量"：导入时转一份低清版。

## 4. 还可以从它借鉴的

| 借鉴 | 它怎么做 | 我们怎么用 |
|---|---|---|
| **不留黑屏，失败有退路** | 实时渲染 → 内嵌视频 → 抓帧 → 明确留空；首帧前用预览图垫底；"还在下载"不算"渲染失败" | 视频加载前先显示外形的锚点图或场景照片；片段坏了换同类片段、记下来，页面上说明 |
| **省电** | 看不见时不播放、不下载；`document.hidden` 会短暂误报，所以要防抖 | M6 待办里的"省电"，桌面身体和网页身体都用 |
| **限帧率转码** | ffmpeg 转码带帧率上限 | 导入时可选 24/30 fps，省电省流量 |
| **整套配置导入导出** | 外观预设快照，导入前先预检 | 我们工坊已有项目导出；扩展成"整个她"（人设、声音、外形设置），为以后的分享做准备 |
| **插件市场展示** | `package.json` 的 `icon`、`screenshots.json`（图放在 Release 上） | dshmarket 里好看很多。图标由代码生成（发布时写进包），截图放 Release，仓库还是纯代码 |
| **新手指南** | 单独一份 `README.beginner.md` | 我们也写一份，给没用过命令行的人 |
| **和 DSH 的接口记账** | `DSH-UI-INTERFACES.md` 记下依赖了 DSH 哪些内部东西；声明 `engines.dsh`；自动检查 | DSH 升级时能很快知道哪里会坏。网页身体要贴着 DSH 界面，这一条更重要 |
| **共存** | 专门处理和其他界面插件同时开的情况 | 她要和壁纸插件能一起用：背景交给它，她只浮在上面 |

踩坑提醒（它踩过的）：
- DSH 桌面版给插件路由加了一道校验头（`x-dsh-desktop-renderer`），严格沙箱的 iframe 拿不到，所以会 403。我们不放进沙箱 iframe，应该碰不到；
- 大文件走 DSH 的路由比较慢，它在桌面版上另开了一个本机端口。我们先走同一个地址，慢了再说。

**不借鉴的**：Wallpaper Engine 的场景渲染（WebWallGL）和工坊壁纸。那是另一个产品的范围，工坊内容的授权也复杂。那个项目 MIT 许可，但我们只借思路，不抄代码。

| 步 | 内容 | 做完能验证什么 |
|---|---|---|
| **0. 摸底** | 试 DSH 的路由：长连接、Range、大文件上传、`immediately`；在桌面版和网页版各试一次 | 这几条都通，方案才成立 |

## 6. 定下来的（2026-11-01，按建议）

1. **方向**：要不要做网页身体。我的建议是做，它能一次解决 VPS、Linux、手机，还不用下载 200 MB。
2. **默认放哪**：我建议浮动小窗（占地方小、不影响看聊天），聊天背景作为选项。
3. **VPS 上的外形**：我建议先做"上传"，不做"服务器上生成视频"。

## 7. 进度（2026-11-01）

**第 0 步，摸底**：读了 DSH 的路由代码（`dsh-client-connection`）。
- 响应是一块一块写出去的，有背压，连接断开时会通知，所以长连接（SSE）和视频 Range 都能走 `connection.fetch`；
- 路由只有精确路径（pack 的文件用查询参数），只给已登录的主人用；
- 请求体有 `buffered` 和 `streaming` 两种，大文件上传可以用 `streaming`（第 2 步用）。

**第 1 步，最小版**：已做，在 her-dev 里（没有桌面身体）实测。

| 改动 | 做什么 |
|---|---|
| `src/pack/` | 外形的加载、导入、形象、设置从身体挪到这里，大脑和身体共用。`loadPack` 能换文件地址（`file:` 或 DSH 的地址） |
| `src/dsh/web-body.ts` | 大脑这边：选外形、提供文件（Range、ETag）、一条长连接（新标签页顶替旧的，她不会说两遍） |
| `src/client/web-bridge.ts` | 浏览器版的 `window.her`，身体的渲染代码一行没改 |
| `src/client/web-float.ts` | DSH 页面里的浮动小窗：拖动、透明处点击穿透、右键菜单、藏起来、"点一下开声音" |
| 设置 → 放在哪里 | 自动 / 一直在网页里 / 不在网页里（默认自动：没有桌面身体时才显示） |

实测通过：
- 透明背景的她站在 DSH 页面上，后面的输入框看得见；
- 视频从大脑的地址播放；
- 拖动并记住位置，透明处能点到后面的东西；
- 双击打字、回答、字幕、声音（`AudioContext` 在运行）；从发出到第一句声音约 5 秒，和桌面身体一样；
- 右键菜单，藏起来和叫回来；
- 换外形（透明桌宠和场景都试了）；
- 在 DSH 各页面之间切换她都在；

还没实测：
- 手机宽度：发现电脑上存的位置会让她跑出屏幕，已改成始终留在屏幕内，改完还没再看一遍；
- 麦克风（代码接好了，要有真实设备试）；
- DSH 桌面版里的网页身体（前面都是 `dsh` 网页版）；
- 真的 VPS（第 3 步）；
- 手机上的触摸操作（现在靠鼠标事件，第 4 步）；
- 同时有桌面身体时的切换（代码是：桌面身体连上就藏起来）。

**第 2 步，大脑自己管外形**：已做，在 her-dev 里（没有桌面身体）走完全程。

| 改动 | 做什么 |
|---|---|
| `src/dsh/uploads.ts` | 上传：边收边写到临时文件，完整了才换上；路径不能跑出目标文件夹，只收视频、图片、声音和文字文件，一个文件最多 2 GB |
| `src/pack/import-look.ts` | 形象导入，桌面身体和大脑共用 |
| `src/pack/frame.ts` | 框人物区，用 ffmpeg 写 `crop.png` 和 `scene.json`（桌面身体用 Electron） |
| `src/client/FrameScene.tsx` | 页面里在照片上拖框 |
| `src/client/ProjectUpload.tsx` | 工坊每张卡片都能上传（参考图、照片、片段），能下载参考图和 `crop.png` |
| 设置 → 外形 | "上传素材文件夹…"，同名文件夹再传一次会替换原来的 |

实测通过（真实片段）：
- 上传素材文件夹，大脑导入 12 秒，她换上；
- 跑出文件夹的路径、不支持的文件都被拒绝，页面能看到原因；
- 工坊全程：新建、上传参考图和片段和照片、在页面上用鼠标框人物区、状态跟着变、`crop.png` 能下载、导入 23 秒（桌宠 + 1 个场景），她换上新形象。

还不能做的：
- 工坊的"导出到文件夹""导入已有项目"还要桌面身体（要弹选文件夹的窗口），网页身体里是灰的，要改成下载和上传；
- "放在聊天背景"、场景按时间自动切换、看不见时暂停省电（第 4 步）。

**第 3 步，VPS 走通**：代码做完，还没在真的 VPS 上试。部署说明见 `docs/VPS部署.md`。

| 改动 | 做什么 |

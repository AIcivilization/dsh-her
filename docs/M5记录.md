# M5 记录：dsh 里的"她"页面（向导 + 管理页）

> 2026-10-29，Apple M1 Pro，macOS 27.2，DSH 0.2.1-rc.3（`her-dev`），模型 WorkBuddy DeepSeek-V4.1-Flash。

## M5 做了什么

**dsh 左侧栏多了"她"**（`src/client/`，和 dsh-mishu 一样的接法：`sidebar.panellist` + `main` 两个插槽，共用一个 id）
- 还没设置过：显示 **7 步向导**。
- 设置完：变成 **管理页**，随时可以"重新走一遍向导"。
- 页面每 2 秒问一次大脑的状态，所以身体连上、导入进度、她听到的话都会自己出现。
- 每个改动都以大脑返回的状态为准，页面不自己猜。
- 颜色全部用 dsh 自己的主题变量，深色和浅色主题下都正常。

**7 步向导**

| 步 | 内容 |
|---|---|
| 1. 检查 | dsh 有没有可用的模型（没有就不能往下走）、本地语音状态、系统 |
| 2. 身体 | 身体有没有连上；没运行时可以一键"启动身体"；也可以先跳过 |
| 3. 外形 | 列出已导入的外形包，点一下就换上；"导入我的素材…"会在身体那台电脑上弹出选文件夹的窗口，进度和检查报告显示在页面上 |
| 4. 人格 | 名字、**她怎么称呼你、提到你时用 他/她/TA**、一句话让模型写成完整人设、人设可直接改、**先试聊几句**（单独调模型，不进她的会话和记忆） |
| 5. 声音 | 10 个推荐音色点一下试听，也可以输入 0–102 的编号；语速；保存后立即生效，不用重启 |
| 6. 麦克风 | 告诉你按哪个快捷键，她听到的话会显示在页面上 |
| 7. 放到桌面 | 浮在最上层 / 住在壁纸里 / 普通窗口 |

**管理页**：概况（身体、大脑、记忆数量、最近听到的话）、**设置**、她记得的事。

**设置**（2026-10-29 加）：她能改的东西都放在这一页，顶上有跳转。
- **模型**：列出 dsh 里能用的全部模型（和 dsh 自己的模型选择器读的是同一份列表），按服务商分组，可以选思考强度；也可以"跟随 dsh 的默认模型"。存在她的人物设置里。因为模型是在打开会话时定的，换模型时会先停下她正在说的话，再用新模型重新接上她的会话，聊过的都还在。实测：换成 GLM-5.3-Flash 后她还记得刚才的对话，但第一句要 13.6 秒；换回 DeepSeek-V4.1-Flash（思考 low）是 4.8 秒。所以页面提示聊天选快模型、思考选 Low。
- **声音**：Edge 和百炼两组音色，点一下试听，语速。
- **外形**：所有外形包（包括本地测试用的那 5 套），点一下就换；导入新素材。
- **放在哪里**：浮在最上层 / 住在壁纸里 / 普通窗口。
- **人格**：名字、称呼、人称、人设、试聊。

桌面上她的右键菜单（和托盘菜单）里，"外形"变成了子菜单，可以直接换。

**她记得的事**：关于你的事实（待确认、敏感的有标记，可以确认、可以忘掉）、事件、日记、"现在整理今天"、导出 Markdown。忘掉之前会再问一次。

**大脑这边**
- `src/core/character.ts`：她的设定存成 `<home>/characters/<cid>/character.json`。第一次启动时用插件配置里的值当默认值。
- `src/dsh/api.ts`：页面用的接口，走 dsh 自己带认证的 `/api` 通道，挂在 `/api/dsh-her/…` 下。
- 她的提示词和每天整理都改为读取设定里的称呼和人称（M4 遗留的"一律写成他"解决了）。
- 换声音时，语音引擎直接切换说话人，不重启。

**身体这边**
- 连上后把外形包列表、正在用的外形、当前模式报给大脑。
- 新消息：`pack.use`（换外形）、`pack.pick`（弹窗选文件夹并导入）。
- 选择保存在 `<home>/body-settings.json`，重启后还在。

## 测试中发现并改掉的问题

1. **主按钮在深色主题下看不见字**：dsh 深色主题的主色接近白色，按钮文字却写死了白色 → 文字改用 dsh 的前景色变量。
2. **换成场景包后她没进壁纸**：模式只在身体启动时决定一次 → 现在你没有亲自选过模式时，换外形会跟着外形包的默认模式走；你选过的模式始终优先。

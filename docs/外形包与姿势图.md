# 外形包与姿势图（P1，视频外形）

> 外形包 = 身体这一侧的"外形"：视频、锚点图、动作清单。人格、音色、记忆不在包里，它们属于大脑里的角色。

---

## 1. 用户不需要写配置文件

用户只要把素材放进一个文件夹，**按 `docs/素材生成提示词.md` 里的规则命名**，导入时程序自动推断出配置文件 `pack.json`。高级用户也可以自己写 `pack.json` 来覆盖推断结果。

文件命名规则：

| 文件名 | 含义 |
|---|---|
| `anchor_<锚点>.png` | 锚点图，例如 `anchor_stand.png` |
| `<锚点>_<角色>_<序号>.mp4` | 在某个锚点上循环的片段，例如 `stand_idle_01.mp4`、`stand_talk_02.mp4`、`stand_happy_01.mp4` |
| `<起点>_to_<终点>.mp4` | 姿势之间的过渡，例如 `sit_to_stand.mp4` |
| `<锚点>_exit_<方向>.mp4` / `off_enter_<方向>[_<换装>].mp4` | 走出画面 / 走进画面 |
| `lines/line_<名字>.mp4` + 同名 `.wav` + `.txt` | 储备台词（视频、音频、文字稿） |
| `plate.png` | 壁纸场景包的空场景图（同时会被设成系统壁纸） |

片段文件名里的"角色"取以下值之一：
- **状态**：`idle`、`listen`、`think`、`talk`、`sleep`
- **情绪**：`happy`、`shy`、`pout`……
- **其他**：任何不属于上面两类的名字（`wave`、`touched`……）都当作动作

## 2. `pack.json`（推断结果，也可以手写）

```json
{
  "format": "dsh-her-pack@1",
  "id": "su-overlay",
  "name": "苏 · 桌宠",
  "version": "1.0.0",
  "kind": "video",
  "layer": "overlay",
  "canvas": { "w": 1080, "h": 1920, "foot": [0.5, 0.97] },
  "background": "chroma:#00B140",
  "anchors": {
    "stand": { "image": "anchor_stand.png" },
    "off": { "empty": true }
  },
  "start": "stand",
  "clips": [
    { "id": "stand_idle_01", "file": "stand_idle_01.mp4", "from": "stand", "to": "stand", "role": "idle", "weight": 3 },
    { "id": "stand_talk_01", "file": "stand_talk_01.mp4", "from": "stand", "to": "stand", "role": "talk" },
    { "id": "stand_wave_01", "file": "stand_wave_01.mp4", "from": "stand", "to": "stand", "role": "action", "action": "wave", "desc": "挥手打招呼" },
    { "id": "stand_exit_right", "file": "stand_exit_right.mp4", "from": "stand", "to": "off", "role": "transition", "interruptible": false },
    { "id": "line_morning", "file": "lines/line_morning.mp4", "audio": "lines/line_morning.wav",
      "transcript": "早呀，今天也要元气满满哦。", "from": "stand", "to": "stand", "role": "line" }
  ],
  "macros": [
    { "action": "outfit_jk", "desc": "离开去换 JK 再回来展示", "steps": ["@off", "off_enter_right_jk", "jk_show_01"] }
  ]
}
```

字段说明：
- `layer`：`overlay`（桌宠包，抠成透明）或 `scene`（壁纸场景包）。
- `background`：
  - `alpha`：视频本身带透明通道。
  - `chroma:#色值`：纯色背景，导入时抠掉。
  - `plate:plate.png`：场景包，背景就是这张图。
- `foot`：脚底在画面里的相对位置，用于在桌面上对齐站位。
- `interruptible`：能否中途打断，默认 `true`。
- `macros`：组合动作。`@off` 表示"先走到 off 锚点"，具体怎么走由寻路决定。

**换装**：每套衣服是一组独立的锚点，用 `锚点@衣服` 命名，比如 `stand@jk`。不同衣服之间只能经过 `off`（人不在画面里）切换，所以永远不会出现"衣服在画面里变来变去"。

## 3. 姿势图怎么运行

```
          sit_to_stand
   [sit] ───────────────► [stand] ──stand_exit_right──► [off]
     ▲  ◄─────────────────   │  ▲                          │
     │     stand_to_sit       │  └──off_enter_right─────────┘
  sit_idle/talk/…        stand_idle/talk/…        off_enter_right_jk ──► [stand@jk]
```

- **节点 = 锚点**，**边 = 片段**。首尾在同一个锚点的片段是"自环"（待机、说话、情绪、动作）。
- **进入某个状态**（比如 `talk`）：在当前锚点的 `talk` 片段池里，按权重随机挑一个，并且不和上一次重复。当前锚点没有这个状态时，按总时长最短的路径走到最近一个有它的锚点。
- **播放某个动作**：找到含这个动作的片段，走过去再播。
- **说话时她不在画面里**：先走进来再开口；进场期间语音排队等待（进场片段一般 2–3 秒）。
- **打断**：当前片段可打断，就交叉淡化 0.3 秒切走；不可打断，就播完再切。
- **情绪 + 说话**：如果有 `talk_happy` 这样的组合片段就用它；没有就先播一下 `happy`，再回到 `talk`。

### 片段之间怎么接

| 情况 | 做法 |
|---|---|
| 上一段尾帧和下一段首帧对得上（导入时检测过） | **硬切**：两个 `<video>` 交替，用 `requestVideoFrameCallback` 在帧边界切换，看不出接缝 |
| 对不上 | 交叉淡化 0.3–0.8 秒兜底（同类项目就是这样做的） |

### 待机不能死循环一段

待机是"片段池 + 权重"：大部分时间播最平静的那段，偶尔插播整理头发、看窗外。长时间没人互动就进入 `sleep`。

## 4. 导入检查（傻瓜化的关键）

导入一个文件夹时，程序按顺序做这几件事。**原文件不动**，处理结果放到 `~/.dsh-her/packs/<id>/`：

1. **认文件名**：推断 `pack.json`。不认识的文件列出来，提示"这个文件不知道是做什么用的"。
2. **查规格**：分辨率、帧率是否一致；时长是否正常；有没有音轨（只有储备台词应该带声音）。
3. **查接缝**：每段的首帧、尾帧和锚点图做相似度比对（ffmpeg 的 SSIM）。分数高的标为"硬切"，低的标为"交叉淡化"，并在报告里告诉你哪一段接缝差、建议重抽。
4. **处理背景**：
   - 桌宠包：抠像后转成**上下叠放的 H.264**：上半是彩色画面，下半是透明遮罩，播放时用 WebGL 合成。这样可以硬件解码，比 VP9 透明视频省约 40% CPU（见 `docs/M0验证记录.md`）。P1 用 ffmpeg 的色键抠绿幕，AI 抠像以后再加。
   - 场景包：转成 H.264，再把 `plate.png` 设成系统壁纸。
5. **生成点击遮罩**：每段按每秒 10 帧、宽 64 像素的精度，预先算好"哪里是她"。运行时点击判断直接查这张表，不用实时读视频像素。
6. **最低要求**：至少有 1 个锚点、1 段 `idle`、1 段 `talk`。不满足时报告缺什么，并允许"用待机片段代替说话片段，先凑合用"。

**报告示例**：

> ✅ 12 段已识别，⚠️ `stand_talk_02` 首尾接缝差（相似度 0.71），将使用交叉淡化，建议重抽；❌ 没有 `listen` 片段，倾听时会用待机代替。

## 5. 开发期：用同类项目的 5 套待机素材

这些素材没有锚点，也没有说话片段。导入时当作"**只有待机池、全部交叉淡化**"的特殊包：
- bg2 是纯黑背景，用亮度抠像，测桌宠模式。
- 其余 4 套背景已经做进画面，用普通窗口模式测试。

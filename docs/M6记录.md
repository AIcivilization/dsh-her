# M6 记录：让别人也能装上（进行中）

> 2026-10-30，Apple M1 Pro，macOS 27.2。先做 mac；Windows 等有测试机。

## 做好了的

### 1. 身体打成一个 app（`body/scripts/package.mjs`，`npm run package`）

- 把 Electron.app 复制成 `dsh-her.app`：身体的代码放在 `Contents/Resources/app`，**ffmpeg 放在 `Contents/Resources/ffmpeg`**（导入素材用，用户电脑上不用装）。
- Info.plist：显示名"她"、只在菜单栏（不占 Dock）、麦克风用途说明、版本号。
- 临时用 ad-hoc 签名（Apple Silicon 不签名的程序跑不起来）。正式发布要换成 Developer ID 签名和公证。
- 输出到仓库的 `release/`（不进 git）：
  - `dsh-her-body-<版本>-darwin-arm64.zip`（约 148 MB，其中 ffmpeg 约 49 MB）；
  - `body-latest.json`：版本，以及每个平台的文件名、大小、SHA-256。
- ffmpeg 默认用 PATH 上的那个，可以用 `--ffmpeg` 指定。脚本会检查它只依赖系统库（放进 app 别人才能用），并在 app 里写一份 `ffmpeg-NOTICE.txt`。
  - **注意许可**：本机这个 ffmpeg 是 `--enable-gpl` 编译的，是 GPL。正式发布前要么换一个 LGPL 的静态版，要么在发布说明里写明 GPL，并给出 ffmpeg 源码地址。

### 2. 插件一键下载、校验、安装、更新身体（`src/dsh/body-install.ts`）

- 从 `body.releases`（默认 `https://github.com/AIcivilization/dsh-her/releases/latest/download/`）读 `body-latest.json`，下载这台电脑的 zip。**大小和 SHA-256 对不上就删掉、不安装**。
- 解压到 `<home>/body/<版本>/dsh-her.app`，写 `<home>/body/current.json`。保留上一个版本，更早的删掉。
- 先用哪个身体：仓库里有开发版就用开发版（你本机就是这样）；没有就用装好的版本。`body.useDev: false` 可以让开发环境也按正式安装的方式走（测试用）。
- 第一次装好后自动启动身体。
- 更新：
  - DSH 启动 1 分钟后检查一次，之后每 6 小时检查一次；有新版本就在后台下载安装；
  - 页面提示"新版本已经装好，重启一下身体就用上了"，并有"重启身体"按钮；
  - 已连上时，身体状态旁边有"检查更新"。
- 「她」页面：没有身体时显示"下载安装身体"，下载时有进度条，失败会说明原因。

### 3. 干净的电脑上 Edge 声音也能装（`src/voice/edge.ts`）

- 新的 mac 只有一个 `/usr/bin/python3`，一运行就弹窗要求装开发者工具。现在只有确认开发者工具已经装好（`xcode-select -p`）时才用它。
- 没有可用的 Python：下载 uv（版本 0.11.26，SHA-256 写死在代码里）放到 `<home>/uv`，由它下载一个自带的 Python 到同一个文件夹，再装 edge-tts。不弹窗，不动系统。装完删掉下载缓存，剩约 115 MB。
- 本机实测（只给系统 PATH，强制走 uv）：24 秒装好，合成一句 3.2 秒的语音正常。

### 4. 第一次发布：0.1.0（2026-10-31）

- 先发过一次 `0.1.0-beta.1`（2026-10-30），npm 上不要带 beta，第二天改成 `0.1.0` 重发。插件和身体用同一个版本号。现在只有 Apple 芯片的 mac 版，还没有 Developer ID 签名。
- 代码：`AIcivilization/dsh-her` 的 main（只有代码和文字，没有图片、视频、音频、模型、压缩包）。
- GitHub Release `v0.1.0`：身体的 zip（148 MB）和 `body-latest.json`。**不标成预发布**：`releases/latest/download/` 会跳过预发布，插件就找不到了。发布说明写明了 ffmpeg 是 GPL 和它的源码地址。
- npm：`dsh-her@0.1.0`，就是 latest，`dsh plugin add dsh-her` 装到的就是它。
- 实测：用插件的安装代码从 GitHub 的 latest 地址下载安装到一个空的 home，23 秒装好，校验通过。
- 发布前修掉：新用户没有任何外形时身体会崩。现在显示一个占位（纯代码画的"她"字圆圈和一句提示），可以拖动、可以聊天。

# 真人桌宠

> 写给收到安装包的人。你不用装 dsh，也不用账号和 API key：解压、打开，她就住到你的桌面上了。想和她聊天，再接上你自己的 Claude Code 或 API key。

朋友发给你一个 `真人桌宠-<名字>-mac.zip` 或 `真人桌宠-<名字>-windows.zip`，里面是两样东西：

- **真人桌宠**：一个让她在桌面上动起来的小程序（身体引擎 [dsh-her](https://github.com/AIcivilization/dsh-her)）。
- **`<名字>.her`**：她本人。名字、样子、什么时候显示什么、被碰时说的话，都在这个文件里，是做她的人的作品。

同一个真人桌宠能装好几个 `.her`，想换谁换谁。

## Mac（Apple 芯片）

1. 双击 zip 解压。**用系统自带的解压**（双击就是）；别的解压工具可能把程序弄坏。
2. 把「真人桌宠」拖进"应用程序"文件夹。
3. 打开"应用程序"里的真人桌宠。第一次系统会拦住它，说"无法验证开发者"（我们还没有苹果的签名）：
   打开 **系统设置 → 隐私与安全性**，往下找到"真人桌宠"那一行，点 **仍要打开**，再输一次密码。只要做一次。
4. 双击 `<名字>.her`。先给你看一眼：谁做的、**许可**、里面有什么。点 **装进来**，她就出来了。

她出来以后，屏幕右上角的菜单栏里有她的名字，点它能：关掉她或叫她出来、换场景、换住的地方、调大小、打开设置、退出。

## Windows（64 位）

1. 在 zip 上点右键 → **全部解压缩**，放在你想放的地方（比如"文档"或 D 盘）。不要在压缩包里直接打开，它会提醒你先解压。
2. 打开解压出来的「真人桌宠」文件夹，双击 **真人桌宠.exe**。
   第一次会出现"Windows 已保护你的电脑"（我们还没有微软的签名）：点 **更多信息**，再点 **仍要运行**。只要做一次。
3. 它会找到同一个文件夹里的 `<名字>.her`，先给你看一眼，点 **装进来**，她就出来了。

她出来以后，屏幕右下角的托盘里有她的图标，右键点它能做和 Mac 上一样的事。

## 她能做什么

- **住在桌面上**：住在壁纸里（桌面图标后面），或者浮在所有窗口上面，两样可以同时开。浮在上面时可以拖动她。
- **按她的日子过**：做她的人排好了什么时候显示什么（早上、晚上、你在不在电脑前、隔一会儿随机换个样子），她就照着来。
- **碰她有反应**：点头、戳一下、按住摸摸头、连着戳，她会动一下，头顶冒一句话。
- **出场和晚安**：她出来时可能先播一小段开机动画，打个招呼；到了安静时段说一句晚安。

不接"大脑"时，她说的都是做她的人写好的话。想和她聊天，见下一节。

## 和她聊天

设置 → **和她聊天** → "她用谁的脑子"，选一个：

- **Claude Code**：你电脑上已经装好、登录好的 Claude Code。它自己的工具都关掉了，她只能聊天，碰不到你的文件。模型可以选（Haiku 快、省）。
- **DeepSeek 或别的 API key**：填你自己的 key（存在系统钥匙串里，Windows 上是只有你能读的文件），服务地址不填就是 DeepSeek。

选好以后，按 **⌃⌥↩**（Windows：Ctrl+Alt+Enter）或双击她，打字和她说话。她会用自己的口吻回答，一句一句地说；开着"她出声"时用微软 Edge 的声音念出来（要联网，第一次会自己装一个小工具，装好之前只出字）。她记得你告诉她的事，下次打开也记得。

要知道的：

- 她每说一句都算在你自己的 Claude 或 API 账号上。各家更建议经常自动用的场合用 API key。
- 这一版只能打字，还听不见你说话；她也还不会先开口。

## 设置

打开设置：菜单栏（Mac）或托盘（Windows）→ **设置…**

- **现在是谁**：换成另一个她，或者把一个移走（不会删除，放在数据文件夹的 `characters/.removed` 里）。
- **再装一个设计包**：选一个 `.her` 文件，或者直接把它拖进设置窗口；也可以双击 `.her`。
- **住在哪**：住在壁纸里、浮在桌面上、大小。
- **她的日子**：按不按编排来、安静时段、开机动画。
- **这个程序**：开机自动启动；更新（见下）；退出。

## 更新

真人桌宠每天看一次有没有新版本：只是去 GitHub 读一个很小的文件，不发送任何关于你的东西。有新版时菜单里会多一项"更新到 x.y.z"，**你点了才下载**；下载完会核对，对了才换上，然后自己重新打开，她和设置都还在。

新版本用着不对，设置里能 **退回** 上一版。不想让它联网，在设置里关掉"每天看一次有没有新版"，它就完全不联网了。

## 隐私

不收集任何东西。不聊天时不要账号、不要 key；聊天时只和你选的那一家说话。她的一切都在你自己的电脑上：

- Mac：`~/Library/Application Support/真人桌宠`
- Windows：`%APPDATA%\真人桌宠`

## 不想要了

先退出（菜单栏或托盘 → 退出）。

- Mac：把"应用程序"里的真人桌宠拖进废纸篓，再删掉上面那个数据文件夹。
- Windows：删掉「真人桌宠」文件夹，再删掉上面那个数据文件夹。

## 关于许可

`.her` 是做她的人的作品，许可写在里面，装之前给你看过。按许可用：比如"CC BY-NC"是不能拿去卖钱的。想把她再发给别人，先看许可允不允许。

## 自己也想做一个？

装 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 和 dsh-her 插件，在「她」页面里调好你的她，然后在「设计包」页点 **生成安装包**，就能做一个这样的 zip 发给别人。设计包的格式见 [设计包格式](设计包格式.md)。

有问题：[反馈问题](https://github.com/AIcivilization/dsh-her/issues)。

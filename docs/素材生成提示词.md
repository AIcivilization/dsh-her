# dsh-her 视频素材生成提示词

> 用途：自己用视频生成工具做第一套"视频角色"素材。
> 工具要求：支持**图生视频 + 首尾帧**（同时指定首帧和尾帧图）。可灵、Vidu、即梦、海螺、Wan FLF2V 等都行。
> 说"储备台词"时，还要一个**音频驱动口型**的工具（如 InfiniteTalk）。

---

## 0. 先选拍哪种包（建议先拍 A）

| 包 | 用在哪 | 背景 | 难点 |
|---|---|---|---|
| **A 桌宠包** | 浮在所有窗口最上面，可拖动 | 纯色背景，后期抠成透明 | 要抠像（我们的工具链会做） |
| **B 壁纸场景包** | 住在壁纸层，桌面图标在她上面 | 一张**全屏照片**铺满桌面，她的视频只覆盖照片上她活动的那一块（不改系统壁纸） | 视频要从照片裁下来的那一块生成，背景才对得上 |

A 更通用：抠完可以放进任何壁纸，也可以放在最上层。B 效果最惊艳，但每换一张壁纸就得重拍。

---

## 1. 硬规则（每一段都要遵守）

1. **锚点姿势**：每段的**首帧和尾帧都用同一张锚点图**。这样段与段之间可以无缝切换。
2. **固定机位**：不推、不拉、不摇、不变焦、不切镜。
3. **同一个人、同一套衣服**：换装算新的一组素材，有自己的锚点图。
4. **画面里什么字都不要**：无字幕、无 UI、无水印、无 Logo、无任务栏和图标（字幕由程序实时画）。
5. **不要声音**：待机和动作片段静音；说话片段的声音由程序实时合成。只有"储备台词"例外，见第 5 节。
6. **时长**：每段 5 秒。说话片段可以做 5–10 秒。
7. **规格**：
   - A 包竖版 9:16（720×1280 起，最好 1080×1920）。
   - B 包：**全屏照片**按屏幕比例（mac 16:10，比如 2560×1600 或 3024×1964；Windows 多是 16:9）；**视频**和"做场景"导出的 crop.png 同样的长宽比（一般 1024 左右就够，不用全屏大小）。
   - 导出 mp4（H.264）。
8. **内容**：成年女性，衣着得体。

---

## 2. 第一步：做锚点图（定妆照）

用生图工具做一张。**后面所有片段的首尾帧都用它**，所以要多抽几次，挑最满意的一张。

### A 桌宠包锚点图

**中文：**
```
一位成年东亚女性的写实全身照，正面站立，身体自然放松，双手自然垂在身体两侧，
看向镜头，嘴巴闭合，温柔的浅笑。[在这里写外貌：发型、发色、五官、身材]。
[在这里写服装：上衣、下装、鞋、配饰]。
纯绿色背景（#00B140），背景完全均匀，无地面、无阴影、无渐变、无任何物体。
柔和均匀的正面棚拍光，人物边缘清晰，头发丝分明。
竖版构图 9:16，人物居中，头顶和脚下各留少量空白。
超写实，真实皮肤质感，真实头发，真实衣料。
```
**English:**
```
Photorealistic full-body photo of an adult East Asian woman, standing facing the camera,
relaxed posture, arms resting naturally at her sides, looking at the viewer,
mouth closed, gentle soft smile. [appearance: hairstyle, hair color, face, body].
[outfit: top, bottom, shoes, accessories].
Solid pure green background (#00B140), perfectly uniform, no floor, no shadow,
no gradient, no objects. Soft even frontal studio lighting, crisp edges, clear hair strands.
Vertical 9:16, centered, small margin above head and below feet.
Ultra-realistic skin, hair and fabric.
```
> 衣服或头发是绿色的，就把背景改成纯灰（#808080）。

### B 壁纸场景包：全屏照片 + 人物区（2026-10-30 改）

做法的开头和常见的做法一样，最后一步不同：**只拿她那一块去生成视频**，视频贴回照片的原位置。背景是原图，清晰不动；视频小，生成快、播放省电。

1. **做全屏照片**（场景里有她）：
   - 常见的办法：把场景图（比如沙发）设成桌面壁纸，截全屏，再把背景透明的人物 PNG 合成进去；
   - 或者直接用 AI 生一张横版全屏图（比例和屏幕一样，2560 宽以上），人在里面。
   - 照片里不要有字、任务栏、图标。
2. **框出人物区**：在 dsh 的「她」页面 → 编排 → 形象工坊，给场景传好这张照片，点"框人物区"，用鼠标框出她活动的范围（留够动作的余量；她要起身、走动，就框大一点），保存。（2026-11-10 起身体右键菜单里不再有"做场景…"。）场景文件夹里会放好：
   - `plate.jpg`（或 png）：照片原样；
   - `scene.json`：照片尺寸和人物区位置，**不要改**；
   - `crop.png`：裁下来的人物区，**用它生成视频**；
   - `怎么继续.txt`。
3. **生成片段**：首帧和尾帧都用 `crop.png`（它就是锚点图 `stand`），长宽比和它一样。提示词加一句：**"人物的动作始终在画面内，背景完全不动"**。
4. 片段按下面的名字命名，放进同一个文件夹，在「她」页面 → 设置 → 外形 →"导入我的素材…"选这个文件夹。

想要"走进来、坐下、换装回来"这种（第 6 节）：人物区框大一些，覆盖她走动的整片区域；`off`（不在画面里）用照片里没有她的版本裁出来的那一块当首帧。

## 4. 片段清单（A 包，锚点 = `stand`）

使用方法：**通用块 + 下面的动作描述**。首帧和尾帧都放锚点图。

### 必须（最少这 3 段，程序就能跑）

| 文件名 | 中文动作描述 | English |
|---|---|---|
| `stand_idle_01.mp4` | 安静站着，自然呼吸，偶尔眨眼，头部极轻微地左右晃动，嘴巴闭合，保持浅笑。 | Standing still, breathing naturally, occasional blinks, very slight head sway, mouth closed, soft smile. |
| `stand_talk_01.mp4` | 看着镜头温柔地说话，嘴巴自然持续开合，伴随轻微点头和很小的手势，表情亲切。最后一秒闭嘴回到原姿势。 | Talking gently to the camera, mouth opening and closing naturally and continuously, slight nods, small hand gestures, warm expression. Closes mouth and returns to the pose in the last second. |
| `stand_talk_02.mp4` | 同上，换一种说话节奏，略带笑意，一只手轻轻抬起又放下。 | Same, different rhythm, slightly smiling, one hand lifts lightly and lowers. |

> 说话片段多做 2–3 个变体，程序会轮换，避免一眼看出重复。

### 推荐（有了会生动很多）

| 文件名 | 中文动作描述 | English |
|---|---|---|
| `stand_listen_01.mp4` | 认真地听人说话，嘴巴闭着，轻轻点头两次，眼神专注看着镜头。 | Listening attentively, mouth closed, nods gently twice, focused eye contact. |
| `stand_think_01.mp4` | 眼睛看向右上方像在思考，食指轻点下巴，然后视线回到镜头。 | Glances up-right as if thinking, index finger taps chin, then looks back at camera. |
| `stand_happy_01.mp4` | 开心地笑出来，眼睛弯起，肩膀轻微耸动，然后恢复浅笑。 | Laughs happily, eyes crinkling, shoulders shake slightly, then back to a soft smile. |
| `stand_shy_01.mp4` | 害羞地低头，用手指卷一下发梢，再抬眼看镜头。 | Shyly looks down, twirls a strand of hair, then glances up at the camera. |
| `stand_wave_01.mp4` | 看到你很开心，抬起右手朝镜头挥手打招呼，然后放下手。 | Happily raises her right hand and waves at the camera, then lowers it. |
| `stand_touched_01.mp4` | 像被轻轻戳了一下，微微一惊，然后看着镜头笑。 | Startled slightly as if poked, then smiles at the camera. |

## 5. 储备台词片段（口型精确）

这类片段**自带声音**，用来说固定的话（早安、晚安、欢迎回来……）。

做法分三步，顺序不能反：

1. **先用她的音色合成这句话的音频**。音色必须和实时语音是同一个，否则一切换就穿帮。音色定下来之前先别做这类片段。
2. 用**音频驱动口型**的工具（如 InfiniteTalk），输入"锚点图 + 这段音频"生成视频。
3. 交付时一起给：`视频.mp4` + `音频.wav` + 一行文字稿。

建议的第一批台词：

| 文件名 | 台词 |
|---|---|
| `line_morning` | 早呀，今天也要元气满满哦。 |
| `line_night` | 不早啦，早点睡，明天见。 |
| `line_welcome_back` | 你回来啦，我等你好久了。 |
| `line_rest` | 已经坐了好久了，起来活动一下，喝口水吧。 |
| `line_task_done` | 你交代的事情办好了，要看看吗？ |
| `line_here` | 嗯，我在呢。 |

## 6. B 包（壁纸场景）的片段

B 包有三个锚点：`sit`（坐着）、`stand`（站着）、`off`（不在画面里，就是空场景）。片段是锚点之间的"边"：

| 文件名 | 从 → 到 | 中文动作描述 |
|---|---|---|
| `sit_idle_01` | sit → sit | 坐在沙发上安静待着，自然呼吸，偶尔整理头发。 |
| `sit_talk_01` | sit → sit | 坐着看镜头说话，口型持续开合，轻微手势。 |
| `sit_to_stand` | sit → stand | 把靠枕放到一边，手撑沙发自然起身，站到沙发前。 |
| `stand_to_sit` | stand → sit | 走回沙发自然坐下，整理一下衣服。 |
| `stand_exit_right` | stand → off | 转身朝画面最右侧走去，完整离开画面。 |
| `off_enter_right` | off → stand | 从画面最右侧自然走进来，站到沙发前，看向镜头。 |
| `off_enter_right_outfit2` | off → stand(换装 2) | 同上，但已经换好第二套衣服（首帧用空场景，尾帧用"换装 2 的 stand 锚点图"）。 |

B 包额外要求：只能从右侧进出，不能瞬移或淡入淡出；换装只能在完全离开画面后发生。

## 7. 交付与检查

文件夹结构：
```
我的角色/
  anchor_stand.png          锚点图
  stand_idle_01.mp4
  stand_talk_01.mp4
  ...
  lines/line_morning.mp4 + line_morning.wav + line_morning.txt
```

拿到每段后自查：

- [ ] 首帧和尾帧是不是和锚点图几乎一样？（首尾连起来循环播放，看有没有跳一下）
- [ ] 脸、发型、衣服有没有变？
- [ ] 背景有没有闪、有没有变色、有没有冒出阴影？
- [ ] 画面里有没有文字、水印？
- [ ] 手有没有画坏？

不合格就换个种子重抽。

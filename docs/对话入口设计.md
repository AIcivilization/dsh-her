# 对话入口

在哪儿都能叫出她，打字说话都行；所有对话都存在 dsh 的"她"工作区里。

## 1. 她的工作区

- **装好就有，排在最上面。** 装好后第一次启动，在左侧工作区建好"她 · 名字"，并移到第一个。以后你自己拖动了顺序，就按你的来，不会每次启动都把它挪回去。
  - DSH 的工作区服务可以调顺序（`insertBefore`），但没有"置顶"标记，所以只在第一次挪。
- **一个人物只有一个工作区。** 现在每个人物有自己的房间文件夹，同一个文件夹只会对应一个工作区。（你侧栏里那几个"她 · 小禾"是测试时用了不同的数据目录留下的，正式用户只会有一个。）
- **每段对话是工作区里的一个会话。** 你从任何地方叫出她说话，都进当前那段会话；工作区里能看到每一段，点开就是完整记录。
- **新开一段**：小条上和 dsh 里都有"新开一段"。旧的那段留在工作区里。
- **接着聊**：默认接着最近那一段说。
- **记忆是共用的**：她记得的事、日记，不管在哪一段里说的，每一段都能用上。所以新开一段不会让她忘了你。
- **自动分段：默认关**，一直接着同一段。设置里可以打开，条件任选一个或几个，满足任一条就新开一段：
  - **按时间**：隔了多久没说话（比如 6 小时）。
  - **按长度**：这一段的对话量到了多少（按她的模型能装下的上限算，比如用到一半）。长度会影响每次回答的费用和速度，页面上显示这一段现在用了多少。
  - **按天**：每天第一次说话时新开一段。
  - 自动新开时，小条上提示一句"新开了一段（原因）"，旧的那段留在工作区。

### 关于"合并"（已定）

DSH 没有把两段对话拼成一段的功能。这里的"合并"指**接着之前那段说**：在小条或工作区里选一段旧的，让它重新成为当前那段，后面的话都进那段。

## 2. 在哪儿都能叫出来：对话小条

一个统一的小条，替换现在的三种输入框（她身上的输入框、壁纸模式的小窗、网页背景模式的输入框）。

```
┌───────────────────────────────────────┐
│ 你：今天面试过了                           │
│ 小禾：真的？！快说说怎么聊的               │  ← 最近 3 句；更多去 dsh
├───────────────────────────────────────┤
│ [🎙]  想和她说点什么…           [新开一段] [完整对话 ↗] │
└───────────────────────────────────────┘
```

- **叫出来**：快捷键 ⌃⌥↩（Windows：Ctrl+Alt+Enter），双击她，点 dsh 对话框上的小头像，托盘菜单。
- **位置**：桌面上在她旁边；她在壁纸里时在屏幕下方中间；网页里贴着小头像。
- **全屏时**：你叫出来的小条盖在全屏程序上面；她的形象和她主动说的话，全屏时不出来。（Mac 上要实测 Electron 能不能盖住全屏程序。）
- **她的回答**：照旧在气泡里出字、出声音，同时出现在小条的最近几句里。长回答在小条里只显示开头，"完整对话"跳到 dsh 里的这段会话。
- **Esc 关掉**；说完一句不自动关，方便接着说。

## 3. 说话的三种方式

| 方式 | 怎么用 | 适合 |
|---|---|---|
| **对讲机：按住图标** | 小条上的 🎙，鼠标按住说，松开发出去 | 手在鼠标上的时候 |
| **对讲机：按住一个键** | 按住某个键说，松开发出去；在哪个程序里都行 | 打游戏、全屏的时候 |
| **一直在听** | 打开后你说话她就听，说完自动发 | 戴耳机长聊 |

另外保留现在的"按一下快捷键说一句"（说完自动停），老用户习惯了。

### 按住一个键：要你决定

- Electron 自带的全局快捷键只知道"按下"，不知道"松开"，做不了"按住说话"。
- 要在任何程序里都能按住说话，得装一个监听键盘的组件（比如 `uiohook-napi`）：
  - **Mac 会弹系统提示，要你在"隐私与安全性 → 辅助功能"里允许 dsh-her。**（这个组件在 Mac 上要的是"辅助功能"权限。）
  - Windows 不用授权。
  - 多一个需要按系统分别打包的组件。
- 不装的话，只有小条打开、并且在最前面时，按住键才算数；在全屏游戏里就用不了。
- **网页里**（VPS、手机）：浏览器只能在页面有焦点时知道按键，所以网页里只有"小条打开时按住键"。手机上用按住图标。

**已定：装，默认关着。** 在设置里打开"任何程序里都能按住说话"时才请求授权，并用大白话说明只听这一个键。键可以在设置里换，默认建议右边的 Option（Windows 是右 Alt），平时很少单独按。

## 4. 网页里

- dsh 对话框上的小头像：点一下弹出小条（不碰 dsh 自己的输入框，你在当前会话里的工作不受影响）。
- 网页背景模式里，"打字给她"也换成这个小条。
- 手机上：小条放在屏幕下方，按住 🎙 说话。

## 5. 先后顺序

1. 工作区：第一次挪到最上面，"新开一段"和"接着之前那段"。
2. 对话小条（桌面、壁纸、网页一个样子），最近 3 句，跳到完整对话。
3. 按住图标说话。
4. 按住一个键说话（键盘监听组件，默认关）。
5. Mac 上小条盖住全屏程序（先实测）。
6. 自动分段的设置（默认关）。

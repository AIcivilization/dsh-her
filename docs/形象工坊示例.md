# 形象工坊的示例

「她」页面 → 编排 → 形象工坊里每一张卡片都有"示例"，从本机的 `~/.dsh-her/examples/workshop/` 读（插件包里也可以带一个 `examples/workshop/` 文件夹，本机的同名文件优先；现在包里不带）。文件还没放的时候，卡片上显示一个占位框，写着要放哪个文件。

样板间的素材做好后，挑出下面这些文件放进来（名字要一样）：

| 文件 | 在哪张卡片 | 放什么 |
|---|---|---|
| `look.png` | 1. 她长什么样 | 做好的她，让人一眼看到角色卡填出来是什么样 |
| `reference.png` | 2. 参考图 | 参考图：纯色背景、全身、正面站立 |
| `desk.mp4` | 3. 桌宠 | 一段桌宠片段（绿幕原片，几秒就行） |
| `desk-keyed.png` | 3. 桌宠 | 抠好后浮在桌面上的截图 |
| `scene-plate.png` | 4. 场景 | 一个场景的全屏照片 |
| `scene-crop.png` | 4. 场景 | 这个场景框好的人物区（crop.png） |
| `scene.mp4` | 4. 场景 | 这个场景的一段片段 |
| `result.png` | 5. 生成、导入 | 导入后桌面上的样子 |

图片用 PNG（文件名照上表），视频用 MP4（H.264），每个文件尽量在 5MB 以内。

**仓库只放代码**：这些图片和视频不进 git（`.gitignore` 挡掉了），放在本机的 `~/.dsh-her/examples/workshop/`（同名文件优先用那里的）。正式发布时，它们和身体程序一样作为 Release 的附件发出去，由插件下载到这个文件夹（还没做）。

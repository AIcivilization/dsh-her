# 产品定义：身体引擎

> 2026-11-14 定。对外介绍（README、插件市场的说明）都按这里的说法。

## 一句话

**dsh-her 是鲸鱼娘的身体引擎**：一个鲸鱼娘所需基本功能的基础设施。设计交给设计者，身体交给我们。

它也是**给所有玩桌宠的人用的身体引擎**：你的角色不一定是鲸鱼娘，换一套设计就是另一个她。

## 谁做什么

| 设计者做的（设计） | 引擎做的（身体） |
|---|---|
| 角色：名字、人设、三视图、头像 / 桌面 / 宠物的图和视频、编排（什么时候显示什么） | 让她动起来：按编排换场景、待机、说话、被碰到时的反应 |
| 界面皮肤：dsh 的颜色、背景、字体、她的对话框 | 说话：多种声音（免费的、付费的、本机的、外接的），口型跟着声音 |
| 开机动画：她出场时的一小段 | 听：麦克风、按住说话、一直在听、打断她 |
| （以后）更多：表情、动作、配件…… | 交互：对话小条、头顶气泡、纯聊模式、触摸、拖动、先开口、记忆 |
| | 住的地方：壁纸里、浮在桌面上、dsh 网页里、手机上、对话框上的小头像 |
| | 设置：多个人物、大小、遮罩、专注、安静时段…… |

设计和引擎之间只有一个约定：**设计包**（见 [设计包格式](设计包格式.md)）。设计者照着标准文档做一个设计包，任何人都能装进来用；用户也能把自己调好的她导出成设计包，发给别人。

## 我们自己的设计

引擎自带一套我们自己的设计（原创的蓝色二次元鲸鱼娘、鲸鱼蓝和深海夜两套皮肤），让装上就能用。它和别人的设计地位一样，都是设计包能表达的东西。

社区里有很多鲸鱼娘的二创和资源（比如 [鲸鱼娘开源资产库](https://treapgogo.github.io/deepseek-whale-girl/)）。我们不拿别人的设计，也不替用户一键搬运；最多在素材指南里放一行链接，用户自己去找灵感。各自独立。

## 在哪儿能玩

- **现在**：装在 DeepSeek Harness（dsh）里，作为 dsh 的插件。她的"大脑"（对话、记忆）用 dsh 的模型和会话。
- **以后**：不玩 dsh 也能玩。把调好的她生成一个独立安装包，像普通应用一样装到桌面上（设计见 [独立安装包设计](独立安装包设计.md)，还没做）。

# 视频身体：Electron 实现要点（P1）

---

## 1. 程序形态

- **独立的桌面程序**："dsh-her 身体"。用 electron-builder 打包，大约 100–150 MB。
- **安装**：插件第一次启用时，在向导里一键下载（从 GitHub Releases 下载，并校验 sha256）；也可以手动下载安装。
- **启动**：插件启动时如果发现身体没在运行，就把它拉起来。**dsh 关掉后身体不退出**，她会去睡觉，等 dsh 回来。可选"开机自启"。
- **版本**：身体和大脑通过协议版本号核对。身体太旧时，向导提示一键更新。

---

## 2. 三种窗口模式

| 模式 | mac | Windows | 能不能点她 |
|---|---|---|---|
| **最上层（桌宠）** | 透明、无边框窗口，`setAlwaysOnTop(true, 'floating')`，所有桌面空间都显示 | 透明、无边框、置顶窗口 | ✅ |
| **住在壁纸里** | **Electron 自带的 `type: 'desktop'` 窗口**：位于桌面层级，在图标下面，不需要原生插件 | **WorkerW 方案**：把窗口挂到桌面图标后面的那层窗口下面。用 `koffi` 直接调用 user32，不需要编译原生模块。要兼容 Windows 11 24H2 改过的窗口结构；Lively Wallpaper 已适配 24H2，可以参考它的做法（它是 GPL 协议，只参考思路，不复制代码） | ❌（壁纸层收不到鼠标） |
| **普通窗口** | 普通窗口 | 普通窗口 | ✅（用于调试，也是兜底） |

**壁纸层"只能看不能点"是两个系统共同的限制**，所以这样设计交互：
- 全局快捷键（默认 `⌃⌥空格` / `Ctrl+Alt+空格`，可以改；`Alt+空格` 在 Windows 上是系统窗口菜单，不能用）：按一下说一句。Electron 的全局快捷键收不到"松开"，做不了"按住说话"。
- 菜单栏 / 托盘图标：叫她、静音、切换模式。
- "叫她出来"：她临时切换到最上层，可以点、可以拖；一段时间没有互动就回到壁纸里。

**兜底**：壁纸层挂载失败时（比如某个 Windows 版本的桌面结构又变了），自动退回到"最上层、贴在屏幕底部"，并在托盘里提示原因。

---

## 3. 点击穿透（最上层模式）

- 窗口默认"鼠标穿透"：`setIgnoreMouseEvents(true, { forward: true })`，穿透的同时仍然能收到鼠标移动事件。
- 鼠标移动时，用导入时预先算好的点击遮罩判断是否在她身上：
  - 在她身上：关闭穿透，可以点、可以拖。
  - 离开她：重新打开穿透。
- **不需要屏幕录制权限**。her-mac 当时依赖这个权限，现在用不到了。

---

## 4. 播放

- 两个 `<video>` 交替播放。硬切时用 `requestVideoFrameCallback` 对齐帧边界，交叉淡化时用 CSS 透明度渐变。
- 桌宠包在导入时就转成"上下叠放的 H.264"（上半彩色、下半遮罩），硬件解码后用 WebGL 合成，运行时不做抠像。M0 实测比 VP9 透明视频省约 40% CPU。
- 声音：用 Web Audio 播放每一句音频，同时计算音量，给需要口型的外形使用。
- 字幕：桌宠模式下显示在她头顶附近；壁纸模式显示在壁纸层里，位置跟随素材里预留的位置（比如左侧居中）。

---

## 5. 省电

- **待机时降低帧率**：视频本身每秒 16–24 帧，界面层没有变化时不重绘。
- **自动暂停**：检测到全屏程序、锁屏、显示器休眠、壁纸被其他窗口完全挡住时暂停。
- **笔记本用电池时**：长时间没有互动就停在一帧上，有互动再恢复。
- **目标**：Apple Silicon 上待机 CPU 低于 3%。P0 就要实测这个数字。

---

## 6. 麦克风

- 默认**按一下快捷键说一句**（说完自动结束），可以切换成"一直在听"。
- 麦克风开着时，托盘图标和她身边都有指示。
- mac：Info.plist 写明麦克风用途；**签名必须稳定**，否则 mac 记不住你给过的麦克风权限（her-mac 踩过的坑）。

---

## 7. 签名与分发

- **mac**：用 Developer ID 签名并公证（notarize），否则用户双击会被系统拦截。
- **Windows**：P1 先不签名，用户会看到 SmartScreen 的"未知发布者"提示，向导里提前说明；以后再加代码签名。

---

## 8. 多显示器、多角色

- 每个角色一个窗口，可以放在任意显示器上，位置按显示器分别记住。
- 屏幕缩放（DPI）变化时，按 `foot`（脚底位置）重新对齐站位。

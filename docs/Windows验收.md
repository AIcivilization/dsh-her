# Windows 验收

竞品的用户几乎都在 Windows 上，而我们在 Windows 上验证得最少。自动检查（CI）只能证明程序能打包、能启动、单元测试能过，下面这些必须在真机上试。

建议用一台没有开发环境的 Win11：没装过 Node、Git 和 ffmpeg。每一项记下通过或没通过，没通过就截图。

## 1. 安装

- [ ] 在 dsh 桌面版的插件页搜 `dsh-her` 并安装，完全退出 dsh 再打开。
- [ ] 打开侧栏的"她"，自动进入向导，第一步的检查项都是绿的（模型除外，模型要自己配）。
- [ ] 点"下载安装身体"，进度条在走；关掉代理再试一次，能换镜像或给出看得懂的提示。
- [ ] 身体装好后自动启动，右下角出现她（或占位的圆形），托盘有图标。
- [ ] 系统弹出的"未知发布者"提示：记下原文和点了什么。

## 2. 说话

- [ ] 双击她打开输入框，打字发送，她出声回答，气泡有字。
- [ ] Ctrl+Alt+空格 说一句，她听到并回答。第一次会下载识别模型（约 170 MB）。
- [ ] 她说话时你开口，她马上停。
- [ ] 外放（不戴耳机）时不会把自己的声音当成你在说话。

## 3. 形象

- [ ] 形象工坊上传参考图和片段，导入成功，她换上新形象。
- [ ] 右键切换：浮在最上层、住在壁纸里、普通窗口。
- [ ] 住在壁纸里时桌面图标还能点。**任何时候都不能改掉系统原来的壁纸。**
- [ ] 住在壁纸里时用托盘菜单打字，她不会跳回浮在最上层。
- [ ] 高分屏（缩放 150%、200%）和双屏下，她的位置和大小正常，拖动不漂移。

## 4. 这次新加的

- [ ] 走完向导，不说话，动动鼠标，一分钟左右她主动打招呼。
- [ ] 点头、点身体，她马上动一下并有短音；隔 8 秒再点，她说一句符合人设的话。
- [ ] 按住不动 1 秒，她摇一下；拖动时只动位置，不说话。
- [ ] 双击只打开输入框，她不说话。
- [ ] 锁屏回来超过 30 分钟，她会说一句（今天说过 3 次就不会，设置页写着原因）。
- [ ] 托盘菜单勾"专注一会儿"，设置页显示专注中；取消后恢复。
- [ ] 设置 → 人设：贴一张人设卡，拆成名字和人设，试聊后保存。
- [ ] 设置 → 主动说话：调次数和安静时段，点"现在让她说一句"。

## 5. 长时间

- [ ] 开着放一小时：任务管理器看 CPU 和内存，记下数字。
- [ ] 睡眠唤醒后，她还在，还能说话。
- [ ] 全屏玩游戏或开视频会议时，她有没有打扰（她看不出别的程序全屏，要靠专注模式）。
- [ ] 卸载插件后，身体退出，系统壁纸还是原来的。

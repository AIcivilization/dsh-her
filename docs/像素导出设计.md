# 像素导出：GIF、微信表情、照片视频当大门

2026-11-21 定的方向，同一天做了。目的：让别人用像素工坊做出好玩的东西，发出去，传开。

主线就一条：**照片或视频 → 会动的像素画 → 导出 GIF → 加到微信表情**。

已经定的事：

| | |
|---|---|
| 先导出什么 | GIF。所有设备、所有聊天软件都能放；像素画颜色少，GIF 不失真、文件小 |
| 默认做成什么 | 微信表情：正方形、透明底、压到 500 KB 以内 |
| 画面上的标志 | 角落的像素小鲸鱼**默认不放**，导出时自己勾 |
| 文件里的标志 | `.js` 开头一行"用 dsh-her 像素工坊做的"加网址；GIF 里有一段注释和动画文件 |
| 主打 | 用照片或视频做，放在最前面 |
| 以后做 | 加字（像素中文字体）、抠人、MP4、整套微信表情打包、项目网页上的轻量版 |

---

## 1. 一圈多长：`info.loop`

GIF 要首尾接上，就得知道动画过多久回到一模一样。

- 动画文件的 `info` 里多一个可以不写的 `loop`（秒，0–60）。旧文件不受影响。写错了会报错，提示里说怎么写。
- 「给大模型的说明」里加了它，并让 AI 循环的周期尽量取整数秒。
- **一键动起来**的八个动作改成整数节拍：浮动 2 秒、呼吸 3 秒、摇摆 2 秒、跳一跳 1.2 秒、走来走去 12 秒（一个来回）、转身 4 秒、闪闪发光 4 秒。代码里是 `const BEAT = …`。
- 多帧的图：换帧一轮是 帧数 × 每帧秒数。节拍会微微伸缩，让整数个节拍正好装进一轮（或者一个节拍正好装下整数轮），两边一起回到开头。比如 3 帧、每帧 0.214 秒（一轮 0.642 秒）摇摆：节拍变成 0.642 × 3 = 1.926 秒。代码在 `src/core/pixel-motion.ts` 的 `pictureTiming`。
- 测试：每个动作、单张和多帧，`t` 和 `t + loop` 画出来的格子一格不差。

## 2. 怎么出 GIF

```
dsh 页面                                  沙盒（和播放用的同一套：iframe + Worker，不能联网）
算出要录哪些时刻（exportPlan） ─────────▶ 按顺序一帧一帧跑动画的 frame
                         ◀──────────── 只交回每帧的格子（一串字节，检查过大小）
首尾柔接 → 裁到画了东西的地方 → 整数倍放大 → 铺背景
→ 挑一套颜色 → 写 GIF（太大就减帧、缩小）→ 显示成一张真的图片
```

- 动画代码只在沙盒里跑，页面只拿字节，安全规矩不变（`src/client/pixel/player.ts` 的 `frames` 命令，`host.ts` 的 `renderFrames`）。
- 做 GIF 的部分全是纯函数（`src/core/pixel-export.ts`、`src/core/pixel-gif.ts`），不碰页面，测试里能跑同一套代码。GIF 编码是我们自己写的（LZW），没有加依赖。

### 2.1 录哪一段（`exportPlan`）

| 动画 | 录多长 | 首尾 |
|---|---|---|
| 写了 `info.loop` | 一圈 | 正好接上 |
| `seconds > 0`（播一遍的） | 一遍 | 播完从头来；**不加**播放时的淡入淡出 |
| 一直循环、没写 loop（比如骰子） | 用户选 2 / 3 / 4 / 6 秒，默认 3 | 默认"首尾柔接"：开头几帧和一圈以后的画面渐变过去，结尾自然流回开头；可以关掉 |

- 帧率：24 → 12，30 → 15，最多 15。GIF 放 12–15 帧就够顺，文件小一半。
- 帧的间隔是 一圈 ÷ 帧数，不是死板的 1/12 秒：1.2 秒一圈录 14 帧，每帧 0.0857 秒，最后一帧之后正好回到第一帧。
- 最长 20 秒，最多 300 帧。

### 2.2 三种做法（`EXPORT_PRESETS`）

| | 尺寸 | 裁剪 | 背景默认 | 大小上限 |
|---|---|---|---|---|
| **微信表情**（默认） | 正方形，至少 240 | 裁到画了东西的地方 | 透明 | 500 KB |
| 方形大图 | 正方形，至少 480 | 裁 | 单色动画深色，彩色透明 | 5 MB |
| 整个画面 | 长边约 480 | 不裁 | 同上 | 8 MB |

- **裁剪**：所有帧里画到的格子合起来，外面留一格。人物不会只占画面中间一小块。
- **只用整数倍放大**，格子边缘清清楚楚；对不齐正方形的部分补透明或背景色。
- **背景**：透明、深色、白色，或者自己选颜色。GIF 的透明只有"有"和"没有"：透明底时，单色动画淡的格子画成深一点的颜色，太淡的不画；彩色的按一半透明度为界。
- **画法**：单色动画可以选方块或圆点；代码字导出成方块或圆点。彩色只有方块。
- **颜色**：不超过 255 种就一种不丢；超过了用中位切分挑 255 种。
- **太大了**：先隔一帧丢一帧，再把格子缩小一档，直到放得下。实在放不下，给最小的那个，并说"微信可能加不上"。

### 2.3 界面

- 像素工坊底下一排多了 **📤 导出 GIF**，点开是导出面板；像素动画列表里每一项也有「导出 GIF」。
- 面板左边显示的是**真正做出来的那张 GIF**，不是播放器的预览。手机上长按就能存。
- 右边：做成什么（三张卡）、背景、画法、录几秒和首尾柔接（只有没写 loop 的才有），一行尺寸、帧数、大小，微信表情时说"✓ 能加到微信表情"或者太大。
- 按钮：下载 GIF；浏览器支持分享文件时多一个「分享…」（手机上能直接发到微信）。
- 一段"怎么加到微信表情"：手机上长按存进相册，在微信里表情 → ＋ → 选这张；电脑上拖进微信发给文件传输助手，再右键添加到表情。
- "更多"里：把原文件藏进 GIF（默认开）、角落放小鲸鱼（默认关）、导出 .js。

## 3. 标志

| 在哪 | 怎么带 |
|---|---|
| `.js` 文件 | 第一行 `// 用 dsh-her 像素工坊做的 · https://aicivilization.github.io/dsh-her/`。图片转的、骰子掷的一生成就有；导出 .js 和藏进 GIF 时，没有就补上（`withBrand`，`src/core/pixel-brand.ts`） |
| GIF 注释 | `Made with dsh-her pixel workshop - <网址>`（纯英文，有的软件只认这个） |
| GIF 里我们自己的块 | 应用扩展块 `DSHHER10` / `PX1`，里面是 `{ v, name, code, look }`。文件太大（超过上限的三分之一）就不藏，面板上说一声 |
| 画面 | 默认什么都没有。勾了才在右下角放一只几格大的像素小鲸鱼，带一圈白边 |

微信、微博这类平台常会重新压缩图片，藏在文件里的东西可能会丢，所以只算附加的。

## 4. 拖回来接着改

- 像素工坊里选文件、或者把文件拖进工坊：如果是一张 GIF，先看里面有没有我们的块。
- 有的话问一句："这张 GIF 是用 dsh-her 做的「名字」，里面带着它的动画文件"，三个按钮：**打开它的文件接着改** / 当普通动图转像素 / 不用了。
- 打开以后是草稿里新的一版，外观用 GIF 里记的那套。代码是别人写的，照样只在沙盒里跑，播之前先试跑。

## 5. 照片和视频当大门

- **图片和视频是两个按钮**（11-21 用户试的时候，同一个名字有 .png 和 .mp4，选到了图片，以为视频没生效）：
  - 像素工坊的空草稿：**🖼 用图片**（一张照片、几张图或动图）和 **🎬 用视频**（一段视频，选其中几秒）两个大按钮放最前面，掷骰子和跟 AI 说排在后面；工坊右边、像素动画页右上角也各有两个按钮。
  - 两个按钮打开的选文件窗口只列自己那一种：图片的只认图片和 GIF，视频的只认 mp4、mov、webm，并且只能选一个。
  - 面板标题写出用的是哪个文件：「🎬 用视频「xxx.mp4」做」。
  - 版本说明按来源写：🎬 视频转的像素动画、🖼 动图转的、几张图转的、图片转的，都带格子大小和帧数。
- **工坊最上面一张卡**（11-21 用户说开始的那块太大、转出来的预览在下面要往下翻）：
  - 空草稿时不再是一大块 16:9 的空画面，而是一张矮的「从哪儿开始？」卡：四个一样大的格子（🖼 用图片、🎬 用视频、🎲 掷骰子、💬 跟 AI 说），图片和视频两格用主题色淡淡标出来；手机上排成 2 × 2。
  - 选了图片或视频，转换面板就**放在最上面，替掉播放画面**：左边是一直在动的像素预览（深色底，放得更大），右边是一排排紧凑的设置（哪一段、格子高、几帧、颜色，三个勾选），「放进草稿」在设置最下面，「不用了」在标题右边。窄的时候上下排。
  - 带原文件的 GIF 的问句也放在最上面。
  - 放进草稿以后，最上面回到播放画面。
- **拖进来**：整个工坊都能放文件，拖的时候有一圈虚线。图片和视频混着拖进来，用视频，并说"一起选了 N 个文件，用的是视频「…」，其余没用"，不会悄悄丢掉。
- **视频选一段**：取 2 / 3 / 4 / 6 秒，滑条选从第几秒开始；停下来 0.35 秒后再重新取帧，不会拖一下取一次。
- **来回播**：正放再倒放，任何视频、动图都能首尾接上；帧数多一倍，文件大小照样检查。

## 6. 还没做的

- **加字**："收到""哈哈哈"这类配字。办法：页面里用一套开源像素中文字体把字画成格子，写进代码里当一张图（沙盒不用装字体）。要先定用哪套字体（看许可），字体用时下载、不进仓库。
- **抠人、抠宠物**：背景乱的随手视频也能用。浏览器里跑抠图模型，模型不进仓库。工作量最大。
- MP4 竖屏视频、单个 HTML、微信表情开放平台整套打包（规格要现查）。
- 项目网页上的轻量版（图片转像素 + 掷骰子 + 导出 GIF，不用 AI）。和《像素工坊设计》"项目网页上不放"相反，还没定。
- 微信表情的大小、尺寸限制我们按保守值（500 KB、240 左右）做的；手机上长按存 GIF 还会不会动、能不能直接加表情，要在 iPhone 和安卓真机上各试一次。

# 让 dsh 里的 AI 帮你装 dsh-her

不想自己看步骤的话，把下面整段发给 dsh 里的 AI，它会替你装好。

```text
请帮我安装 dsh 插件 dsh-her（https://github.com/AIcivilization/dsh-her），按这些步骤来，每步告诉我结果：

1. 先看我在用哪个 profile：桌面版一般是 desktop，网页版或 VPS 一般是 web。不确定就问我。
2. 运行 dsh plugin --profile <profile> add dsh-her
   如果提示没有 pnpm，运行 npm i -g pnpm 再试。Node.js 要 22.18 或更新。
3. 告诉我：要完全退出 dsh 再打开（桌面版要从菜单退出，不是关窗口），插件才会生效。
4. 重启之后，让我打开侧栏的"她"，跟着向导走。

不要帮我填任何 API key、密码或令牌：需要的话告诉我去哪里填，我自己来。
不要改我的系统设置和壁纸。
```

## 装好之后

向导会带你选身体（桌面程序或网页）、外形、人设、声音。

在 dsh 桌面版里也可以不找 AI：打开插件页，搜 `dsh-her`，点安装。

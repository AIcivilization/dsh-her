# 预设形象

主要路径还是用户按规格自己做、自己上传（形象工坊）。这里是一个入口：你做好几套放到 Release 上，页面上就多一排"现成的形象"，用户点一下就能用。Release 上没有列表时，这一排不显示。

预设已经是做好的外形包，用户不需要 ffmpeg，也不需要素材。

## 怎么加一套

1. 在形象工坊把她做好、导入，确认效果。
2. 打包（文件都在 `release/presets/`，这个目录不进 git）：

```bash
node scripts/make-preset.mjs --look 形象id --id xiaohe --name 小禾 --desc "二十五岁的插画师" --project "形象工坊文件夹" --preview 预览图.png
```

   - `--look`：`~/.dsh-her/looks` 下的文件夹名。
   - `--id`：给用户的名字，只能用小写字母、数字和横线，发布后不要改。
   - `--project`：可选，从这里带上她在对话框上的小头像。
   - `--preview`：可选，3 MB 以内的图片。
   - 再运行一次就把新的一套加进同一个 `presets.json`。

3. 把 `release/presets/` 里的所有文件传到最新的 Release 上。页面读的是 `releases/latest/download/presets.json`，所以**每次发新版本都要把这些文件一起带上**，否则列表就不见了。

## 安全

- 列表只从 GitHub 读，不走镜像。列表里有每个文件的大小和 SHA-256，下载（可以走镜像）后核对，对不上就删掉。
- 解开前先看里面的路径，解开后再检查：只能有 `packs/<id>…` 和 `looks/<id>`，不能有链接文件。
- 文件名和 id 不合规矩的条目直接忽略。

## 发布之前

- 要确认素材的授权（用哪家生成的，就看哪家的条款）。
- 她要是虚构的成年人，穿着得体；不要用真人的脸和声音。
- 生成内容要按规定告诉用户这是 AI 生成的。

# 设计：生成独立安装包（讨论稿，2026-11-14，还没写代码）

> 用户的想法：在总览里加一个选项，把调好的她一键打包成安装包。拿到安装包的人**不用装 dsh**，像普通应用一样装上，她就住在桌面背景里、活在桌面上。这一份是思考和方案，等用户拍板再做。

## 1. 先说结论

- **能做，而且设计包格式正好是关键**：安装包 = 我们提前做好的"播放器"程序 + 一个设计包。
- **"生成安装包"不需要在用户电脑上编译**：从我们的 GitHub Release 下载对应系统的播放器，旁边放上从现在的她导出的设计包，打成一个 zip。Mac 上也能生成 Windows 的，反过来也行。
- **难点不在打包，在"大脑"**：现在她的对话、记忆用的是 dsh 的模型和会话。没有 dsh，要么她不聊天（只当桌宠），要么让拿到安装包的人填自己的 API key。建议分两步走。

## 2. 现在的东西哪些能直接用

| 部分 | 现在在哪 | 不用 dsh 能不能用 |
|---|---|---|
| 身体（Electron 桌面程序：壁纸里、浮在桌面上、触摸、拖动、大小、开机动画、托盘） | `body/` | **能**：它本来就是独立程序，只通过本机的协议和大脑说话 |
| 协议服务（身体连大脑的那一头） | `src/server/` | **能**：不依赖 dsh |
| 编排、外形包、形象、素材检查 | `src/pack/` | **能** |
| 人设、提示词、声音（Edge、Ming）、记忆、说话断句 | `src/core/`、`src/voice/`、`src/memory/` | **能**：当初就规定这些不依赖 dsh |
| 她的会话（模型、工具、对话记录） | `src/dsh/her-session.ts` | **不能**：用的是 dsh 的 agents 服务 |
| 设置页 | `src/client/`（React 网页） | 网页本身能用，但现在挂在 dsh 的页面里 |
| 皮肤 | 换的是 dsh 的界面 | 没有 dsh 就没有意义，安装包里不带 |

所以要新写的是一个**独立的小大脑**（`src/standalone/`）：用上面那些能用的部分，加一个不依赖 dsh 的对话模块，再用一个自己的小网页服务把设置页挂出来。身体一行不用改。

## 3. 安装包里是什么

```
她-小禾-mac.zip
├── 小禾.app            播放器（身体 + 独立大脑），和我们 Release 上的一模一样
├── design.zip          设计包：从现在的她导出的（人设、编排、素材、三视图、开机动画）
└── 说明.txt            怎么装、第一次打开要怎么点
```

- **设计包放在 app 旁边，不塞进 app 里**：Mac 的 app 改了里面的文件，签名就坏了，系统会拒绝打开。放在旁边，第一次打开时播放器把它导进自己的文件夹。好处是同一个播放器能放任何设计包：拿到别人的设计包，拖给播放器就换了一个她。
- **Windows** 同样是 zip（以后可以在 CI 里用 NSIS 做一个真正的安装程序 .exe）。
- **大小**：Mac 约 150 MB，Windows 约 210 MB，加上设计包（看素材多少，一般几 MB 到几十 MB）。
- **不会带的**：记忆、对话、模型设置、API key、皮肤。

## 4. 拿到安装包的人能玩到什么（分两步）

**第一步：桌宠版（不聊天，不联网，不要 key）**

- 住在壁纸里、浮在桌面上（四个开关里的两个）、大小、托盘图标；
- 按编排换场景：时间段、你在不在、隔一会儿随机；
- 碰她有反应，说几句设计包里写好的话（设计包里加一个可选的 `lines`：被摸头、打招呼、晚安……，见下文）；
- 开机动画；
- 一个很小的设置窗口：开关、大小、换一个设计包、退出。

这一步大脑很小，主要是把编排变成"现在显示什么"（这段代码已经有），基本不会出错，也不涉及任何账号和隐私。

**第二步：能聊天（拿到的人填自己的 key）**

- 第一次打开问"要不要和她聊天"：填一个 DeepSeek（或 OpenAI 兼容）的 API key，存进系统钥匙串（Mac）或权限 600 的文件（Windows），绝不进安装包；
- 对话小条、头顶气泡、纯聊模式、Edge 的声音（免费，要联网）、记忆、先开口；
- 听你说话（本机识别模型，第一次用时下载）；本机 Ming 声音（Mac）。

第二步的工作量主要在"不依赖 dsh 的对话模块"：发请求、流式拿回答、断句给声音、保存对话、把记忆和人设放进提示词。这些逻辑现在散在 `src/dsh/plugin.ts` 里，要先抽出来，dsh 版和独立版共用。

## 5. "生成安装包"怎么用

在总览（或「设计包」页）加一个"生成安装包"：

1. 选给谁用：Mac（Apple 芯片）、Windows，或两个都要；
2. 选带哪几部分（和"导出设计包"一样：人设、编排和素材、三视图、开机动画），填作者和许可；
3. 程序去我们的 Release 下载对应的播放器（第一次要下载，约 150–210 MB，**下载前先问**），和设计包一起打成 zip，存到"下载"文件夹；
4. 提示：
   - 素材里有别人的图、视频、字体时，要有对方的许可才能发出去；许可写"仅个人使用"的设计包不能生成给别人。
   - 我们没有苹果和微软的签名证书，对方第一次打开会被系统拦：Mac 要右键 →"打开"，Windows 要点"仍要运行"。安装包里的说明.txt 会写清楚。

## 6. 要你拍板的

1. **第一版做到哪一步**：只做桌宠版（建议，快、稳、不碰 key），还是一开始就带聊天？
2. **设计包放 app 旁边**（建议，能换任何设计包，不坏签名）还是塞进 app 里（拿到的人少一步，但 Mac 签名会坏）？
3. **播放器叫什么**：比如"鲸鱼娘桌宠"、"身体引擎"，或者用设计包里她的名字（"小禾"）当应用名。
4. **签名**：要不要以后申请苹果开发者账号（每年 99 美元）做正式签名和公证，让对方打开时不被拦？

## 7. 做的时候的顺序（拍板以后）

1. 设计包格式加可选的 `lines`（写好的台词）。
2. 抽出不依赖 dsh 的大脑核心；独立小大脑先跑桌宠版。
3. 播放器在 CI 里打 Mac、Windows 两个包，和桌面程序一起发到 Release。
4. "生成安装包"按钮。
5. 第二步：聊天、声音、记忆。

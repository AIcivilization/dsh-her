# 她先开口、碰她有反应

她不只等你说话：你回到电脑前，她会打招呼；有日子的事快到了，她会提一句；你碰她，她马上有反应。

## 她什么时候开口

每分钟看一次（你回到电脑前时马上看一次）。下面任何一条不满足，她就不开口，页面上写着原因（设置 → 主动说话）。

| 条件 | 默认 |
|---|---|
| 主动说话开着，不在专注中 | 开着；专注可选 2 小时或到你关掉 |
| 向导走完了，身体连着 | |
| 你在电脑前 | 键盘鼠标 2 分钟内动过；锁屏算不在 |
| 不在安静时段 | 23:30 到 8:30 |
| 她没在说话 | |
| 今天还没说够 | 每天最多 3 次 |
| 你们 30 分钟内没聊过 | |
| 离她上次开口够久 | 90 分钟，你每没回一次就翻一倍 |
| 没有连着 3 次不理她 | 到 3 次就等你先开口 |

条件都满足后，按这个顺序选一件事说：快到日子的事（今天或明天，同一件只提一次）→ 今天第一次见面 → 你离开 30 分钟以上刚回来 → 很久没说话（2.5 到 5 小时随机）。

## 为什么不走她的会话

一句开场白是单独的一次小模型调用，限时 45 秒：

- 模型卡住或出错，她只是不说话，30 分钟后再试，不会把会话卡在"忙"上，也不会让会话越来越长。
- 她说过的话记下来，在你下一句话之前告诉她的会话，所以你接话时她知道自己刚说了什么。
- 你在她想词的时候开口了，这句就作废。

她看不到屏幕，也听不到你，所以提示词要求她不要假装知道你此刻在做什么（实测发现她会编"你键盘声断断续续的"）。

## 怎么知道你在不在

- **桌面身体**：只看键盘鼠标闲了多久、屏幕有没有锁（Electron 的 `powerMonitor`），不看屏幕内容。
- **网页身体**：这个标签页有没有显示、你多久没在页面里动过。
- 每 30 秒报告一次，3 分钟没报告就算不知道，不知道就不开口。旧版身体不报告，所以更新身体之前她不会主动说话。
- **做不到的**：Electron 看不出别的程序是否全屏，所以开会、打游戏时她可能开口。这时用专注模式（她的右键菜单、托盘菜单、设置页）。

## 碰她

| 操作 | 她的反应 |
|---|---|
| 点头部（身形上面 30%） | 马上轻轻一缩，加一声短音 |
| 点身体 | 马上轻轻一晃，加一声短音 |
| 按住 0.7 秒不动 | 慢慢摇一下 |
| 拖动 | 还是拖动，不算碰她 |
| 双击 | 还是打开输入框，她不说话 |

动作和声音都在身体里，不等大脑，也不需要文件（CSS 动画和合成的短音）。

然后大脑决定说不说话：

- 8 秒内最多说一句；10 秒内碰了 5 下以上，换成"被戳个没完"的台词。她正在说话时只动不说。
- 台词按她的人设，让模型一次写好 24 句存起来（`touch-lines.json`），之后每次碰都不花钱、马上有。人设改了就重写；没写好之前用中性的"嗯？"。
- 外形包里有 `touch_head`、`touch_body` 或 `touch` 动作就播；没有就用 `shy`、`happy`、`smile` 表情。
- 你怎么碰了她，也会在下一句话之前告诉她的会话。
- 碰她算你理她了，不再算"没回"。

手机上手指点她也有反应（网页把点击转给她）；这一点只做了模拟测试，没有真机测过。

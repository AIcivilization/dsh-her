# M2 记录：语音

> 2026-10-28，Apple M1 Pro，macOS 27.2，DSH 0.2.1-rc.3（`her-dev`），身体 Electron 44.7。
> 本地语音：SenseVoice（识别）+ Kokoro v1.1 fp32（合成，音色 sid 3），sherpa-onnx，CPU。

## 做了什么

**大脑**
- **音频帧**：协议里先发二进制音频帧，再发写明流编号的消息，两边都由服务端配对（`src/server/brain-server.ts`）。
- **语音服务**（`src/voice/voice.ts`）：
  - 缺模型时在后台下载，下载完之前她只用文字回复。
  - 启动时先合成一句"嗯"预热。
  - 8 个字以内的短句缓存起来。
  - 识别 16 kHz PCM16 录音。
- **合成队列**（`src/voice/speech-queue.ts`）：所有回复共用一条串行队列，句子按顺序合成、合成好一句就发一句。被打断时，没合成的句子丢掉，正在合成的那句结果也不发。
- **第一句提前切**：一段回复的第一句满 8 个字、碰到逗号就切开，让第一个声音尽早出来。
- **念之前清理**：去掉链接、Markdown、代码、表演标记（`src/core/speakable.ts`）。字幕仍显示原文。
- **打断记账**：身体上报"第几句、播了多少毫秒"。大脑据此算出你实际听到的部分，在下一轮之前用 `agent.inject` 告诉她，不会触发她回答。
- **回声判断**（`src/core/echo.ts`）：插话后 10 秒内识别到的内容，如果大部分是她自己刚说的话（按两字组重合度），或者只是"嗯""啊"这类语气词，就丢掉，不算你的话。

**身体**
- **按句播放**（`renderer/speech-player.ts`）：每句的字幕在它的声音开始时才出现，字和声音对得上。
- **麦克风**（`renderer/mic.ts`）：16 kHz 采集，开启浏览器自带的回声消除、降噪和自动增益。两种收听方式：
  - **按一下说一句**（默认）：按 ⌃⌥空格听一句，说完自动结束；8 秒没开口也会结束，麦克风随之关闭。
  - **一直在听**：在菜单里勾选。
  - 原计划是"按住说话"，但 Electron 的全局快捷键收不到"松开"事件，所以改成按一下。
- **判断说话起止**（`renderer/vad.ts`，按能量）：
  - 噪声底随环境自动调整。
  - 超过阈值持续 120 ms 算开口，会补上开口前 300 ms 的音频。
  - 静音 700 ms 算说完。
  - 不足 300 ms 的当作噪声丢掉。
- **插话**：她说话时你一开口，她在本地立刻停下，并上报打断的位置。
- **回声兜底**：插话后被大脑判定为回声或语气词，记一次误触发；30 秒内两次，就关掉插话，改成她说完再听，并提示"戴耳机会好很多"。
- 麦克风开着时，她脚下有一个呼吸的小圆点，听到声音时变绿。
- 开发参数 `--her-debug`（暴露测试钩子，可以注入录音）和 `--her-mute`（静音播放）。原来叫 `--debug`，会被 Electron 当成 Node 的调试参数。

## 验收（用合成的"你说的话"注入身体，走完整链路）

| 项 | 结果 |
|---|---|
| 说完 → 她开口（从录音结束到第一个声音开始播放） | **2229 / 2410 / 2863 / 2537 ms，中位数约 2.5 秒** ✅（目标 ≤ 3 秒） |
| 其中识别 | 31–119 ms |
| 其中模型出第一句 | 约 1.6–2.2 s（WorkBuddy DeepSeek-V4.1-Flash，思考强度 High） |
| 其中合成第一句 | 约 0.2–0.5 s（得益于提前切出的短句） |
| 插话打断 | ✅ 讲故事讲到第 3 句、播了 1532 ms 时打断；大脑记下你听到的是"……那天晚上风雨特" |
| 她知道自己被打断在哪 | ✅ 问"你还记得我刚才让你讲什么吗"，她答："上回刚说到'那天晚上风雨特别大'你就把我打断了，后面那一截你还没听到呢。要接着讲吗？" |
| 回声 / 语气词误触发 → 自动改为说完再听 | ✅ 两次后切换，并提示戴耳机 |
| 单元测试 | 36 个通过（新增：合成队列、听到多少、文字清理、第一句提前切、VAD、回声判断、音频帧配对） |

## 还没验证 / 没做

- **真人对着麦克风说话**：这台机器上我没法出声。需要你亲手试：按 ⌃⌥空格说一句、她说话时插话、外放和戴耳机各试一下。第一次会弹出麦克风权限请求。
- **云端克隆音色（阿里云 CosyVoice）**：合成接口已经按"可替换"设计，但没有 API key，还没接。
- **默认音色**：现在用的是 sid 3，等你从 `~/.dsh-her-dev/logs/voice-bench/` 的样本里挑一个。
- **Windows**：没测。
- 能量 VAD 在嘈杂环境下可能误触发；不够用时换成 silero VAD（模型已经下载好了）。

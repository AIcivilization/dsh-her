# 设计包格式（dsh-her-design@1）

> 给设计者的标准文档。dsh-her 是鲸鱼娘的身体引擎（见 [产品定义](产品定义.md)）：引擎负责让她动、说话、听、交互，**设计**由你来做。照这份文档做一个设计包，任何装了 dsh-her 的人都能在「她 → 设计包」里装进来；他们也能把自己调好的她导出成设计包，发给别人。

## 1. 设计包是什么

一个 **zip 文件**。里面一个 `design.json`（说明这是什么、谁做的、什么许可），加上它用到的图片、视频和几个小文件。

一个设计包可以只装一样东西，也可以装好几样：

| 部分 | 是什么 | 装进来以后 |
|---|---|---|
| **角色** | 名字、人设、称呼、建议的声音 | 变成一个**新的人物**（不会覆盖已有的人物） |
| **编排** | 什么时候显示什么：头像、桌面、宠物一行一行，场景一列一列 | 变成那个新人物的编排，装好就按它来 |
| **素材** | 编排用到的图片、视频、SVG，还有三视图 | 放进素材库（重名的自动改名，编排里跟着改） |
| **皮肤** | dsh 界面的颜色、背景、字体、她的对话框 | 变成一套新皮肤，可以选择马上换上 |
| **开机动画** | 她出场时播的一小段 | 放进素材库，可以选择设成开机动画 |

所以：做皮肤的人发一个只有皮肤的包，做开机动画的人发一个只有开机动画的包，做角色的人发一个"角色 + 编排 + 素材"的包，都可以。

## 2. 文件夹的样子

zip 里可以直接是这些文件，也可以外面再套一层文件夹（比如 `sakura-sugar/design.json`）：

```
design.json            必须有
cover.png              可以没有：封面，16:9，建议 1280×720，1 MB 以内
README.md              可以没有：给人看的说明（引擎不读）
stage.json             可以没有：编排
library/               可以没有：素材，一行一个文件夹
  avatar/  发呆.mp4  说话.mp4  定格.png …
  desktop/ 窗边白天.mp4 …
  pet/     站着.webm …
  intro/   出场.webm
  sheet/   三视图.png
skin/                  可以没有：皮肤，一个完整的皮肤文件夹
  skin.json  background.svg …
```

- **素材的名字就是文件名**（不带扩展名）：`library/avatar/发呆.mp4` 的名字是"发呆"，编排里就写"发呆"。
- 素材的尺寸、格式、怎么做，见 [素材规格与提示词](素材规格与提示词.md)。
- 只能放这些文件：图片（png、jpg、webp、gif、avif、svg）、视频（mp4、webm、mov、m4v）、字体（woff2、woff、ttf、otf，只在 skin/ 里）、`skin.json`、`.css`（只在 skin/ 里）、`stage.json`、`design.json`、`cover.*`、`README.md`。别的文件不收，并会列出来。
- 限制：整个包解开不超过 500 MB，文件不超过 300 个。
- 安全：SVG 里能运行的东西（脚本、点击事件、外部链接）会被去掉；皮肤的 CSS 里不能有 `url()` 和 `@import`。

## 3. design.json

```json
{
  "format": "dsh-her-design@1",
  "id": "sakura-sugar",
  "name": "樱花糖",
  "version": "1.0.0",
  "author": "你的名字",
  "license": "CC BY-NC-SA 4.0",
  "homepage": "https://github.com/you/sakura-sugar",
  "description": "一个樱粉色的她，带一套同色皮肤和出场动画。",
  "engine": "0.9.0",
  "cover": "cover.png",
  "character": {
    "name": "樱花糖",
    "persona": "你是樱花糖，二十岁，……",
    "callYou": "你",
    "pronoun": "他",
    "voice": { "id": "zh-CN-XiaoyiNeural", "speed": 1.0 },
    "sheet": "三视图"
  },
  "stage": "stage.json",
  "skin": "skin",
  "intro": { "material": "出场", "when": "daily" }
}
```

| 字段 | 必须 | 说明 |
|---|---|---|
| `format` | 是 | 固定写 `dsh-her-design@1` |
| `id` | 是 | 小写字母、数字和 `-`，2–40 个字；同一个作者的包不要重复 |
| `name` | 是 | 显示的名字，40 个字以内 |
| `version` | 是 | 版本号，比如 `1.0.0` |
| `author` | 是 | 作者 |
| `license` | 是 | 许可。写标准名字（`CC BY 4.0`、`CC BY-SA 4.0`、`CC BY-NC-SA 4.0`、`MIT` 等）或一句话（比如"仅个人使用，不许转发"）。**装之前会显眼地给用户看** |
| `homepage` | 否 | 主页或下载页（https 开头） |
| `description` | 否 | 一两句话 |
| `engine` | 否 | 需要的最低 dsh-her 版本；比装的版本新时会提醒 |
| `cover` | 否 | 封面图的文件名 |
| `character` | 否 | 角色（见下） |
| `stage` | 否 | 编排文件名，一般是 `stage.json` |
| `skin` | 否 | 皮肤文件夹名，一般是 `skin` |
| `intro` | 否 | 开机动画：`material` 是 `library/intro/` 里一个素材的名字，`when` 是 `every`（每次出场）或 `daily`（每天第一次） |

**character**：

| 字段 | 必须 | 说明 |
|---|---|---|
| `name` | 是 | 她叫什么，20 个字以内 |
| `persona` | 是 | 人设，3000 字以内；用第二人称写（"你是……"） |
| `callYou` | 否 | 她怎么称呼用户 |
| `pronoun` | 否 | 她提到用户时用 `他`、`她` 或 `TA` |
| `voice` | 否 | 建议的声音：`id` 是 dsh-her 的声音 id（比如 Edge 的 `zh-CN-XiaoxiaoNeural`），`speed` 0.5–2。用户那边没有这个声音时用他现在的 |
| `sheet` | 否 | `library/sheet/` 里一张图的名字，会设成她的三视图 |

不放进设计包的：模型（用户自己选）、记忆和对话（属于用户）、API key（永远不放）。

## 4. 编排（stage.json）

和「她 → 编排」页面保存的文件一样（格式 `dsh-her-stage@1`）。几条要点：

- `rows` 是哪几行：`skin`、`avatar`、`desktop`、`pet`。
- `scenes` 是一列一列的场景，第一列是"初始"。每个场景有 `id`、`name`，可以有 `when`（什么时候出现）、`hold`（持续多久）、`about`（给她看的一句说明，"她自己选"的场景要写）。
- 格子 `cells.<行>.use` 里写素材的名字（就是 `library/<行>/` 里的文件名去掉扩展名），可以写几个，`pick` 写 `rotate`（轮换）或 `random`（随机）。
- 时机 `when` 的写法、几个场景同时成立时谁赢，见 [设置页与编排设计 §3](设置页与编排设计.md)。

最省事的做法：在自己的 dsh-her 里把编排调好，在「设计包」里导出，再按需要改 `design.json`。

## 5. 皮肤（skin/）

一个完整的皮肤文件夹：`skin.json` 加它用到的背景图、字体。写法见「她 → 皮肤 → 做一套新皮肤」里的五步和颜色对照表，或者下载那里的模板。

## 6. 装进来的时候

1. 用户在「她 → 设计包」里选一个 zip。
2. 先**预览**：封面、名字、版本、作者、**许可**、说明、里面有什么、哪里有问题。这一步什么都不写。
3. 用户勾要装哪几部分，看过许可，点"装进来"：
   - 角色（连同编排和素材）→ 一个新人物，可以选择装好就换成她；
   - 皮肤 → 一套新皮肤，可以选择马上换上；
   - 开机动画 → 可以选择设成开机动画；
   - 没有角色的素材 → 直接进素材库。
4. 装过的设计包记在「已装的设计包」里：名字、作者、许可、主页，方便注明出处。

不会覆盖用户已有的东西：人物总是新建；素材和皮肤重名时自动换个名字（编排里跟着改）。

## 7. 导出

「她 → 设计包 → 导出」：从现在这个人物导出，勾选要带上的部分——人设、编排和它用到的素材、三视图、现在的皮肤（你自己的）、开机动画（素材库里的）；填名字、作者、版本、许可、说明；得到一个 zip。

编排里用了"外形包"（形象工坊导入的那种）的格子不会导出，导出时会列出来。

## 8. 发布你的设计包

- 放在 GitHub 的 Release 里、网盘里，或者直接发给朋友都行。
- **一定写清许可**，并确认你有权这样发布：图片、视频、字体如果是别人的，要有对方的许可。
- 真人的脸和声音要本人同意。

## 9. 版本

- 格式名里的 `@1` 是格式的版本。以后加新字段不改版本号，旧的引擎不认识的字段会忽略。
- 只有改了已有字段的意思才会变成 `@2`，那时引擎会同时认 `@1`。

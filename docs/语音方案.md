# 语音方案（P1）

> 目标：**不需要显卡**，mac 和 Windows 都能用，装好就能说话；想要更好听、想用自己的音色，再一步升级。

---

## 1. 总览

| 环节 | 在哪里 | P1 默认 | 可选升级 |
|---|---|---|---|
| 判断你开口了、说完了（VAD） | 身体 | silero VAD（在 Electron 里用 onnxruntime-web 跑，CPU） | — |
| 回声消除、降噪 | 身体 | Chromium 自带（调用麦克风时开启 `echoCancellation` / `noiseSuppression`） | — |
| 语音识别 | 大脑 | **SenseVoice-small int8**，通过 `sherpa-onnx-node` 在 CPU 上跑；支持中、英、日、韩、粤语 | 用户自己的 Whisper / FunASR 服务 |
| 语音合成 | 大脑 | **Kokoro v1.1 中英文版（fp32，365 MB）**，通过 `sherpa-onnx-node` 在 CPU 上跑，零配置，内置 103 个音色。M0 实测一句约 1 秒、实时率约 0.35（M1 Pro，4 线程）；int8 版在 ARM 上反而慢一倍 | ① 阿里云百炼 CosyVoice（克隆音色）② 兼容 OpenAI 接口的自建服务（CosyVoice、GPT-SoVITS、OmniVoice……） |

选 `sherpa-onnx` 的理由：
- 它有官方的 Node 原生模块，mac、Windows、Linux 都有预编译版本，不用装 Python，也不用 WSL。
- 识别（SenseVoice）和合成（Kokoro）都在同一个库里。
- 模型文件第一次使用时才下载（几百 MB），有进度条，并提供国内镜像。

---

## 2. 语音合成分三档

| 档 | 效果 | 成本 | 需要什么 |
|---|---|---|---|
| **本地免费（默认）** | 清晰、自然度中等；**不能克隆音色** | 免费 | 什么都不要 |
| **云端克隆（推荐升级）** | 自然、有感情；10–20 秒录音就能克隆 | 按字数计费（官方页面列的是每万字 1.5–2 元，以控制台为准）。粗算聊一小时她说三千字左右，不到一元 | 阿里云百炼的 API key |
| **自建服务（高级）** | 看用户自己的模型 | 自己的显卡 | 一个兼容 OpenAI `/v1/audio/speech` 的地址 |

为什么云端首选 CosyVoice：
- 中文效果好，支持 10–20 秒克隆。
- 有 HTTP 接口。
- 国内能直接访问。

火山引擎（豆包）、MiniMax 也都能克隆音色，以后按同一个合成接口逐个加入。

所有合成引擎都实现同一个接口：

```ts
interface TtsProvider {
  id: string
  voices(): Promise<Voice[]>
  synth(text: string, opts: { voice: string; emotion?: string; signal?: AbortSignal }):
    Promise<{ audio: Uint8Array; format: 'wav' | 'mp3' | 'opus'; durationMs: number; marks?: CharMark[] }>
  clone?(sample: Uint8Array, transcript?: string): Promise<Voice>
}
```

## 3. 速度上的几个做法

- **按句合成，边生成边念**：第一句一出来就开始合成，不等整段回复写完。
- **启动时预热**：先合成一句不播放的话，避免第一次开口要等十几秒（同类项目踩过这个坑）。
- **常用短句缓存**：比如"嗯""我在呢""好呀"，开口前直接用缓存，零等待。
- **思考时间用画面掩盖**：等待回复期间播"思考"片段。

---

## 4. 音色和储备台词必须一致

- 储备台词的音频，必须用**当前角色的音色**合成。
- 换了音色，向导会提示"这 6 段储备台词是旧音色，要重新生成吗？"。重新生成之前，这几段储备台词先停用，改由实时语音来说。

---

## 5. 隐私和密钥

- 识别和本地合成都在本机完成，声音不出电脑。
- 用云端合成时，**只发送她要说的文字**，不发送你的录音；克隆音色时才上传那段样本录音，并且要确认这是你本人的声音，或者你有授权。
- API key 存进系统钥匙串（和小秘书的做法一样）。

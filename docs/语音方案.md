# 语音方案（P1）

> 目标：**不需要显卡**，mac 和 Windows 都能用，装好就能说话；想要更好听、想用自己的音色，再一步升级。

---

## 1. 总览

| 环节 | 在哪里 | P1 默认 | 可选升级 |
|---|---|---|---|
| 判断你开口了、说完了（VAD） | 身体 | silero VAD（在 Electron 里用 onnxruntime-web 跑，CPU） | — |
| 回声消除、降噪 | 身体 | Chromium 自带（调用麦克风时开启 `echoCancellation` / `noiseSuppression`） | — |
| 语音识别 | 大脑 | **SenseVoice-small int8**，通过 `sherpa-onnx-node` 在 CPU 上跑；支持中、英、日、韩、粤语 | 用户自己的 Whisper / FunASR 服务 |
| 语音合成 | 大脑 | **微软 Edge 的声音**（通过开源工具 edge-tts），默认晓晓，免费 | 阿里云百炼 CosyVoice（要 key 和付费额度）；克隆你自己的声音（待做） |

识别选 `sherpa-onnx` 的理由：
- 它有官方的 Node 原生模块，mac、Windows、Linux 都有预编译版本，不用装 Python，也不用 WSL。
- 模型第一次使用时才下载（约 170 MB）。

---

## 2. 语音合成：Edge 为主，百炼可选（2026-10-29 改定）

**为什么不再用本地合成**：M2 用的 Kokoro v1.1（本地、免费）中文是一个字一个字往外蹦的，连读、轻声、语调都很弱。实测确认配置没错（中文词典和分词都加载了），是这个小模型本身的短板，换音色解决不了。中文更自然的本地模型（CosyVoice、IndexTTS、GPT-SoVITS 等）都要 Python、几个 GB 的模型，最好还有 NVIDIA 显卡，没法做成一键安装（参考视频和同类项目就是这么做的）。所以 Kokoro 去掉了，也不再下载它。

**用哪个服务，由音色决定**（`src/core/voices.ts`）：在"她"页面里选了 Edge 的音色就用 Edge，选了百炼的音色就用百炼。

### 2.1 微软 Edge（默认）

- 和 dsh-audiobook 一样，调用开源命令行工具 [edge-tts](https://github.com/rany2/edge-tts)，**不自己连微软的服务**。
- 工具从哪里来：先找已经装好的（dsh-her 自己的 `<home>/edge-tts`、dsh-audiobook 或 dsh-tingdong 装的、Homebrew 装的）；都没有就在后台用 python3 建一个独立的虚拟环境装上（删掉目录即卸载）。没有 python3 时页面会提示。
- 每句话调用一次，输出 24 kHz、48 kbps 的 MP3；码率固定，所以按字节数就能算出时长。身体本来就能播 MP3。
- 7 个女声：晓晓、晓伊、曉臻、曉雨、晓北（东北话）、晓妮（陕西话）、曉曼（粤语）。语速用 `--rate` 传。
- **慢在哪里**：edge-tts 每句话都新开一条连接，光加密握手就要约 1.3 秒，一句话合成要 2.3–2.7 秒。让连接一直开着能快到 1 秒以内，但那要在我们的代码里绕过微软在这个接口上加的防机器人签名，所以没有做。
- **怎么掩盖**：朗读队列一次提前合成 3 句（见第 3 节），所以只有每次回复的第一句要等，后面的句子在她说第一句时就已经好了。
- 免费，但要联网，而且**不是微软公开的正式接口**，可能哪天失效。失效时她只用文字回答，可以在页面上换成百炼的音色。

### 2.2 阿里云百炼 CosyVoice（可选）

- 她说的每一句话，发给百炼 CosyVoice（`cosyvoice-v3-flash`）合成，要的是 24 kHz 的 PCM 原始音频，在大脑里包成 WAV，时长精确。
- 一条 WebSocket 连接一直开着，每句话一个任务（run-task → continue-task → finish-task）。你一开口（或打字发出），大脑就先把连接打开，不让她的第一句话等连接。
- 连接被服务器断开时自动重连并重试一次；某一句被云端拒绝时不重试，这句只显示文字，下一句照常。
- **国内站和国际站都支持**：key 只在它所在的地区有效。先连国内（北京）地址，key 被拒就换国际站（新加坡）地址，记住能用的那个。用户不用选地区。
- 没有 key、key 不对、**额度用完**（包括账号开着"仅使用免费额度"）、云端出错：这句只显示文字，回复继续。前三种情况 30 秒内不再尝试，30 秒后重新读 key 再试，所以**加了 key、开通了付费都不用重启**。"她"页面会写明是哪种情况、怎么解决。
- 12 个年轻女声，按字数计费，以百炼控制台为准。2026-10-29 实测：开发用的国际站账号免费额度已用完，所以还没听过它的实际效果。

### 2.3 以后可以加的

- 微软官方的 Azure 语音：同一批 Edge 的声音，正式接口，可以一直保持连接（一句不到 1 秒），免费档每月 50 万字。
- 火山引擎（豆包语音）、MiniMax：情感好、能克隆，要付费。
- 有 NVIDIA 显卡的用户：接本地的语音服务（GPT-SoVITS、CosyVoice 等），像参考视频那样。

### 2.4 实测（2026-10-29，M1 Pro，Edge 晓晓）

用文字发给她，从发出到第一句的声音到达身体：**约 4.0–4.2 秒**（大模型出第一句约 1.6–2 秒，加上 Edge 合成约 2.5 秒）。之前 Kokoro 时约 2.5 秒。后面几句和第一句几乎同时到，句子之间没有空档。

## 3. 速度上的几个做法

- **按句合成，边生成边念**：第一句一出来就开始合成，不等整段回复写完。
- **提前合成**：朗读队列同时合成接下来的 3 句，按顺序发出；慢的语音服务只让每次回复的第一句等待。
- **启动时预热**：先合成一句不播放的话，避免第一次开口要等十几秒（同类项目踩过这个坑）。
- **常用短句缓存**：比如"嗯""我在呢""好呀"，开口前直接用缓存，零等待。
- **思考时间用画面掩盖**：等待回复期间播"思考"片段。

---

## 4. 音色和储备台词必须一致

- 储备台词的音频，必须用**当前角色的音色**合成。
- 换了音色，向导会提示"这 6 段储备台词是旧音色，要重新生成吗？"。重新生成之前，这几段储备台词先停用，改由实时语音来说。

---

## 5. 隐私和密钥

- 识别在本机完成，你的声音不出电脑。
- 合成时**只发送她要说的文字**，不发送你的录音；克隆音色时才上传那段样本录音，并且要确认这是你本人的声音，或者你有授权。
- 百炼的 API key 不进任何文件：优先读环境变量 `DASHSCOPE_API_KEY`，mac 上读系统钥匙串（`security add-generic-password -a dsh-her -s dsh-her-dashscope -w`）。Windows 目前只支持环境变量。

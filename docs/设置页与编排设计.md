# 设置页、编排、皮肤（设计稿，2026-11-10）

一句话：**我们给引擎、规格和一套初始的鲸鱼娘；怎么摆、怎么播、长什么样，交给玩家。** 只想用默认鲸鱼娘的人，装好就能用，不用看这页的大部分内容。

## 0. 已经定下来的

- 不改名，还是 dsh-her。默认角色是原创的蓝色二次元**鲸鱼娘**，外形要和别家的鲸鱼娘明显不同。
- **去掉一键生成**（`docs/一键生成设计.md` 作废），不替用户做图做视频。工坊里一步步教生成的部分，换成一页"规格和玩法"：尺寸、命名、初始提示词、示例。
- 设置页分四页：**主界面、引擎、鲸鱼娘、编排**。主界面、鲸鱼娘、编排都有示意图，所见即所得。
- **设置只留 dsh 里的这一份。** 身体自己的设置窗口（人设、她记得的事、画面、做场景）去掉，身体只留右键菜单；菜单里的"设置…"打开 dsh 里的设置页。
- 编排按用户提的样子做：从上到下几行，每行"初始 + 场景 + …… + 加号"，最上一排是缩略图，每类有上传入口和格子素材库。**场景按列共用**（§3）。
- 头像等可以设多个素材，选**随机**或**轮换**。
- **皮肤**是一整套设计（颜色、背景图、字体……），改的是 dsh 本身的界面；放在主界面；点一个看一个，保存才生效。**开机动画**和皮肤放在一起。
- 语音要能接外面的服务，第一批包括**讯飞**。
- 以后做（现在设计时要接得上）：2D 动画身体、分享站。

## 2. 素材库

### 2.1 分类（就是编排表的行）

| 行 | 是什么 | 可以放 |
|---|---|---|
| **皮肤** | dsh 整个界面的样子 | 皮肤包（§4） |
| **头像** | dsh 对话框上、网页小窗里的小头像 | 图片（PNG、WebP、SVG）、短视频、动图 |
| **桌面** | 壁纸那一层：整屏的背景。里面可以有她（现在的壁纸模式），也可以只是背景 | 整屏视频、照片；照片加上"她站在哪块区域"的小视频（现在的"做场景"） |
| **宠物** | 浮在桌面最上层的她（现在的"浮在最上层"） | 透明背景的视频；以后加 SVG 和 2D |
| 配件（以后） | 摆在桌面上的小东西 | 图片、SVG、小视频 |

按现在的代码，"宠物"就是外形里的桌宠（look 的 `desk`），"桌面"就是场景包。**这个理解如果不对，以这里改。**

### 2.2 上传

- 每一行有自己的"上传到 ××"。可以选文件，也可以**一次拖进一整个文件夹**。
- **文件名就是名字**：`打麻将.webm` 就叫"打麻将"，之后可以改名。
- 上传时自动做现在导入外形包做的事：转成身体能流畅播放的格式，生成点击用的遮罩，检查首尾能不能接上。
- **检查但不拒绝**。比例不对、不是透明背景、太长、首尾接不上，都照样收下，在格子上标黄，写明哪里不对、会怎么处理（比如"比例不对，两边会留空"）。只有打不开的文件才不收。
- **姿势（可选）**：按现在的命名规则（`stand_idle_01.mp4`、`stand_to_sit.mp4`）起名的视频，会记下开头和结尾的姿势，播放时自动走过渡片段；随便起名的视频没有姿势，切换时淡入淡出。所以老玩家的外形包照样好用，新玩家不用学命名规则。

### 2.3 格子

- 每行一组格子，标题写数量：头像（10）、桌面（5）。
- 格子显示第一帧，鼠标停上去就播放（手机上点一下播）。
- 每个格子能看到：名字、时长、用在哪几列、有没有问题。
- 可以改名、删除。删除前提示"这个素材用在 3 个场景里"。
- 文件放在 `<home>/library/<行>/` 下；仓库里不放任何素材。

## 3. 编排

### 3.1 样子

```
            [缩略图]   [缩略图]   [缩略图]    [缩略图]     [缩略图]
             初始       说话时      被摸头       夜里         打麻将        [＋]
             平时       她开口      碰头·一次    23:00–7:00   她说〔打麻将〕
  皮肤      鲸鱼蓝      沿用        沿用         深海夜        沿用
  头像      发呆 托腮   说话        害羞         睡觉         麻将1 麻将2
            画圈圈·轮换                                       ·随机
  桌面      海面.mp4    沿用        沿用         星空.mp4     麻将桌.mp4
  宠物      游 吐泡泡   挥手        转圈         睡           沿用
            ·随机
```

- **一行**是一类东西（§2.1）。
- **一列**是一个场景。第一列永远是"初始"。点 ＋ 加一列。
- **一格**是这个场景下这一行用哪些素材。点开下拉，列出这一行已经上传的素材，可以多选。
- **空着＝沿用**：用比它低一层的场景的（§3.5），最后落到"初始"。所以不用每格都填。
- **最上一排**是每个场景整体的样子（§3.8）。

### 3.2 一列（场景）有什么

| 项 | 说明 |
|---|---|
| 名字 | 随便起："打麻将""发呆""下雨天" |
| 说明 | 一句话，给她看的："陪你打麻将，手里摸着牌"。她靠这句话决定什么时候进这个场景（§3.7） |
| 什么时候 | §3.3 里选一个或几个，满足任何一个就进 |
| 播多久 | 播一遍就回去／条件满足时一直在／持续几分钟 |
| 开关 | 暂时不用这一列，不用删 |

### 3.3 什么时候（内置的时机）

| 时机 | 来自哪里 |
|---|---|
| 平时（初始） | 没有别的场景时 |
| 她开口、她说完 | 她的语音开始和结束 |
| 你在说 | 麦克风听到你说话 |
| 她在想 | 等她回答的时候 |
| 被摸头、被碰身体（点一下／按住） | 触摸 |
| 你回来了、你一直在用电脑、你很久没动 | 系统的空闲时间（只看多久没碰键盘鼠标） |
| 时间段 | 比如 23:00–7:00，可以跨过半夜 |
| 安静时段 | 引擎里设的那段（默认 23:30–8:30） |
| 她先开口时 | 她主动说话那一刻 |
| 隔一会儿随机 | 比如每 10–30 分钟随机进一次，适合"发呆""画圈圈" |
| 她自己选 | 她在回答里决定（§3.7） |
| 你说了 | 你跟她说"去打会儿麻将吧"，她进这个场景 |

以后可以加：特殊日子（生日、节日）、天气、正在全屏。

### 3.4 一格里有几个素材时

- **轮换**：一个接一个，播完一轮从头来。
- **随机**：每次随便挑一个，不连着挑同一个。
- 以后可以加：按顺序只播一遍、按权重（某个多出现一点）。
- 默认：头像和宠物用轮换，桌面用随机。

### 3.5 几个场景同时成立时

比如夜里（持续）她又开口说话（一下子）。规则：

1. **分层**，从高到低：一下子的事（被碰、开口、你在说）＞ 她自己选的、你说了的 ＞ 持续的条件（你很久没动、时间段、安静时段）＞ 初始。
2. **同一层里，右边的列优先**。列可以拖动换位置。
3. **每一行单独往下找**：夜里她开口时，头像用"说话时"那格，桌面那格空着，就往下找到"夜里"的星空。

### 3.6 换的时候

- 首尾姿势对得上就直接接，对不上就淡入淡出（现在已经这样做了）。
- **桌面**这种整屏的变化，沿用现在场景切换的规矩：自动切换之间至少隔 20 分钟（可以改）；她在说话、在听你说时不切，等这一轮完；可以锁定在当前场景；你说了的马上切。
- **皮肤**只跟"初始"和持续的条件（时间段、安静时段）走，不跟一下子的事走，免得她一开口整个 dsh 就变色。
- 一下子的事播完，回到当时该在的场景。

### 3.7 她自己选：最开放的一条

- 玩家加的每一列，**名字加说明**都交给她，成为她能做的动作（现在的 `play_action`）。
- 聊到麻将，她可以自己进"打麻将"；你说"去睡吧"，她进"睡觉"。
- 所以玩家定义了什么场景，她就能演什么，不需要我们预先想到。
- 她选场景也受 §3.6 的规矩约束（比如桌面 20 分钟）。

### 3.8 缩略图、试看、保存

- **缩略图**：固定尺寸（16:9），用每格第一个素材的第一帧拼成：桌面在底，宠物在它的位置上，右边画一个 dsh 窗口，小头像在对话框上。保存后重新生成。
- 点缩略图：放大播放这个场景。
- **试看**：改了表格，缩略图马上跟着变；点"在桌面上试试"，真的身体也换成这个样子。
- **保存才生效**。不保存就离开，一切回到原样。
- **每次保存留一个版本**（留最近 20 个），可以退回去。

### 3.9 位置和大小

- 点开大舞台，可以拖宠物的位置、拉大小；桌面里"她站在哪块区域"也在这里调（现在的"做场景"）。
- 位置按屏幕的比例记，换了屏幕不会乱。
- 头像的位置由 dsh 的对话框决定，这里只调大小和圆形还是方形。

### 3.10 编排文件

编排存在 `<home>/stages/<id>/stage.json`。高手可以直接手写。

```json
{
  "format": "dsh-her-stage@1",
  "name": "鲸鱼娘·默认",
  "rows": ["skin", "avatar", "desktop", "pet"],
  "scenes": [
    { "id": "base", "name": "初始",
      "cells": {
        "skin": { "use": ["鲸鱼蓝"] },
        "avatar": { "use": ["发呆", "托腮", "画圈圈"], "pick": "rotate" },
        "desktop": { "use": ["海面"] },
        "pet": { "use": ["游", "吐泡泡"], "pick": "random" } } },
    { "id": "talk", "name": "说话时", "when": [{ "on": "her-speaking" }], "hold": "while",
      "cells": { "avatar": { "use": ["说话"] }, "pet": { "use": ["挥手"] } } },
    { "id": "night", "name": "夜里", "when": [{ "on": "hours", "hours": "23-7" }], "hold": "while",
      "cells": { "skin": { "use": ["深海夜"] }, "avatar": { "use": ["睡觉"] },
                 "desktop": { "use": ["星空"] }, "pet": { "use": ["睡"] } } },
    { "id": "mahjong", "name": "打麻将", "about": "陪你打麻将，手里摸着牌",
      "when": [{ "on": "she-chooses" }, { "on": "you-ask" }], "hold": { "minutes": 15 },
      "cells": { "avatar": { "use": ["麻将1", "麻将2"], "pick": "random" },
                 "desktop": { "use": ["麻将桌"] } } }
  ],
  "place": { "pet": { "x": 0.82, "y": 0.9, "height": 0.35 } }
}
```

- 素材按名字找（素材库里的名字）。
- **不认识的字段原样保留**，以后的版本和别人的工具加的东西不会被吃掉。
- 导入或手改后检查一遍，有问题说出来（"打麻将那一格用了'麻将3'，素材库里没有"），不会悄悄丢掉。
- **一份编排加上它用到的素材＝一个"编排包"**。以后分享站分享的就是它。

### 3.11 现有外形包怎么过来

第一次打开新版时自动转换。只新建编排文件，不动原来的文件；转得不对可以退回旧的。

| 现在 | 转成 |
|---|---|
| 浮在最上层的外形包 | 宠物这一行的素材 |
| 场景包、照片加小视频的场景 | 桌面这一行的素材 |
| 待机、听、想、说、睡 | 初始、你在说、她在想、说话时、安静时段 这几列 |
| 情绪（开心、害羞……）、动作（挥手……） | 各自一列，"她自己选" |
| 外形里按时间段、按你在不在换的场景 | 桌面行的列，时机照搬 |
| 头像.png／头像.mp4 | 头像行的初始 |
| 储备台词 | 不变，仍随声音走 |

### 3.12 网页身体和手机

- 同一份编排：桌面行＝网页背景，宠物行＝网页里的小人，头像行＝小头像。
- 手机上表格太宽：每一行一张卡片，卡片里横着划过各列。

## 4. 皮肤和开机动画（在主界面）

### 4.1 一套皮肤是一个文件夹

```
皮肤/鲸鱼蓝/
  skin.json        名字、作者、版本，下面这些东西用哪个
  背景.webp        可选
  字体.woff2       可选
  出场.webm        可选，开机动画
  提示音.ogg       可选
  skin.css         可选，高手自己的样式
```

`skin.json` 里写：

- **配色**：浅色一套、深色一套。
- **背景**：图、怎么铺、多暗。
- **字体**：字体名，或者包里的字体文件。
- **我们自己的东西**：对话小条、气泡的颜色和圆角。
- **开机动画、提示音**用哪个。

### 4.2 怎么换上去

- **配色走 dsh 官方的主题接口**：注册一个主题，或者覆盖它的界面颜色，每个颜色给浅色和深色两个值。dsh 升级也不容易坏。
- **背景图、字体、`skin.css`** 是我们自己盖上去的样式。dsh 改版时可能要跟着修；`skin.css` 在页面上标明"高级，dsh 升级后可能要改"。
- 只选颜色的皮肤，在 dsh 自己的浅色和深色之间切换时跟着变。

### 4.3 怎么选

- 主界面一个下拉，列出已上传的皮肤。第一项是"dsh 原样"。
- **点一个看一个**：整个 dsh 立刻变成那个样子。
- 点"保存"才生效；点"取消"或者离开这页，回到原来的样子。
- 编排表里的"皮肤"行和这里是同一个选择，两个入口。
- 上传：选文件夹或压缩包。检查 `skin.json`，有问题说出来。

### 4.4 字体

- 中文字体一个就有 5–20 MB。
- 很多商用字体不允许随皮肤分发。以后分享站上的皮肤只收可以自由分发的字体（比如思源、霞鹜文楷），或者只写字体名，让用户自己装。

### 4.5 开机动画

| 哪种 | 什么时候播 | 能做到什么 |
|---|---|---|
| **她出场** | 开机后或身体启动时 | 完全由我们控制，比如她从屏幕下方游上来 |
| **打开 dsh** | dsh 页面出来以后 | dsh 自己的启动画面换不了；只能在页面出来后叠 1–3 秒 |

- 设置：开关；选哪段（可以用皮肤自带的）；每次都播，还是每天只播第一次；点一下跳过。
- 格式：透明视频、SVG 动画，或者皮肤里的样式动画。

### 4.6 和别的插件

壁纸、主题类的插件也会改 dsh 的背景。同一时间只能有一个管背景：发现别的插件在管时，提示一句，让用户选。

### 4.7 参考

Obsidian 的主题市场（一个说明文件加一份样式）、VS Code 主题、Wallpaper Engine，以及早年网站的换肤。只借思路，不抄代码和素材。

## 5. SVG

- **作为一种素材加进来，不替换视频。** 适合：头像、配件、皮肤里的装饰和图标、开机动画；以后的 2D 身体。
- 不替换视频的原因：
  - AI 生图出来的是位图；自动转成 SVG 会得到成千上万条没名字的线，文件不小，也找不到"衣服"那一块。
  - 视频的光影和动作 SVG 做不出来。
  - 整屏的 SVG 动画一直动，比视频更费电脑。
- **能让 AI 改的 SVG** 要分好层、起好名：`<g id="头发">`、`<g id="衣服">`、`<g id="眼睛">`……，色块清楚。具体要求写进鲸鱼娘规格（§8）。
- **安全**：SVG 里能藏脚本和外链。上传和导入时清掉脚本、事件、外部链接、`foreignObject`，只按图片显示。
- **2D 身体（以后）**：本质就是"分好层的矢量鲸鱼娘，加上我们的动作逻辑"，在编排里只是宠物行的另一种素材。Live2D 是二次元圈的行业标准，但它的开发包有授权条款，到时候单独看。

## 6. "+AI"：让 dsh 的模型帮你改

### 6.1 能不能做

dsh 的输入框有公开的"放入文字"的方法，插件也可以临时接管输入框（做的时候再核对具体接口）。所以能做。

### 6.2 怎么用

1. 能改的东西旁边有一个"+AI"：一套皮肤、编排表的一格或一列、一个 SVG 头像、开机动画。
2. 点了以后，dsh 里打开一段**"设计"会话**，要改的东西已经带进输入框。这段会话放在她的工作区里，但不算她的聊天，免得和她的对话混在一起。
3. 你说"把衣服换成墨绿色""夜里 11 点后让她睡觉，桌面换星空"，它去改。
4. 改完进**试看**：缩略图和真实画面都变，你点保存才生效。每次保存留版本，改坏了能退回。

### 6.3 它能改什么

| 能 | 不能 |
|---|---|
| SVG（颜色、形状、分层的部件） | 位图、视频的内容 |
| 皮肤（配色、字体、样式） | 只能帮你排、帮你挑、写提示词让你拿去别的工具跑 |
| 编排（加列、改时机、换素材、调位置） | |

- dsh 的模型（DeepSeek）只出文字，所以 SVG 和编排正好是它擅长改的。
- 如果用户自己装了能生图的 dsh 插件，设计会话也能用上；我们不内置生图。
- 设计会话只能改 `<home>` 里的编排、皮肤、素材库，改不到别的地方。

### 6.4 以后：她自己换

你在聊天里说"换件墨绿的衣服吧"，她用同一套工具给自己换，问你"好看吗？"。保存还是你点。放在"+AI"之后做。

## 7. 开放语音

### 7.1 接口

- **说**：文字进去，声音出来（有的服务还给每个字的时间）。口型和说话动作只看声音有多长，所以换哪家都不受影响。
- **听**：声音进去，文字出来。

### 7.2 第一批

| 哪家 | 说 | 听 | 要什么 |
|---|---|---|---|
| Edge、百炼、本机 Ming（现有） | ✓ | | 照旧 |
| **讯飞** | ✓ | ✓ | APPID、APIKey、APISecret |
| **通用接口**（OpenAI 兼容格式） | ✓ | ✓ | 地址、key（可选）、音色名。很多云服务和本地服务都支持 |
| **GPT-SoVITS** | ✓ | | 自己搭的服务地址、参考音频 |
| **别的 dsh 插件** | ✓ | ✓ | 留一个口子，插件按我们写清楚的接口提供 |

- key 照旧：Mac 存钥匙串；VPS、Windows 存权限 600 的 `secrets.json`；不进聊天、不进日志。
- **克隆真人的声音要本人同意**。

**结构**（像系统设置那样）：

- 顶上一条她的名片：头像、名字、一句话状态、开关（她在 / 关着）。
- 左边一列导航，分四组，点哪项右边就是哪项，不再折叠：

| 组 | 项 |
|---|---|
| （无） | 总览 |

## 12. 多个人物（0.8.0）

可以设好几个人物，想用哪个用哪个。

- **放在哪儿**：`<home>/characters/<cid>/`，每人一个文件夹。第一个人物是插件配置里的那个（`character.id`），一直在，不能删。现在用的是谁记在 `<home>/active.json`。
- **跟着人物走的**：人设、称呼、声音、模型（`character.json`）；记忆（`memory/`）；对话和她在 dsh 里的工作区（`session.json`、`room/`）；主动说话的设置和记录；编排和它的版本（`stages/`，以前在 `<home>/stages`，第一次启动时拷给第一个人物）；她穿的形象（`character.look`）；她的三视图（`character.sheet`）。
- **大家共用的**：素材库、皮肤和开机动画、外接语音的服务和 key、桌面程序本身、"关掉她"、四个地方的开关。
- **怎么换**：「人设」页顶上一排人物卡，点谁就是谁；名片上也有一个"换人物"的小下拉。卡片上：头像（或名字的第一个字）、名字、人设的第一句。"新人物"可以起名字，可以勾"照着现在这位复制一份"（人设、模型、形象；记忆不复制）。不在用的可以删：文件夹挪到 `characters/.removed/`，不是真的删掉。最多 12 个。
- **换的时候发生什么**：大脑是按"现在这个人物"运行的一个内部插件；换人就是把它整个关掉（会话、声音、给身体的服务、定时器都挂在它的 context 上）再为新人物开一遍。桌面程序自己会重新连上，收到新名字。页面上出一条"正在换成 ×××"，几秒后整页换成她的。
- **形象跟着换**：换人后两个身体（桌面、网页）都标成"还穿着上一位的"。网页的在大脑起来时换；桌面的在它连上时发一条 `pack.use`。她按编排来，就先把她的编排重新写成 `look:stage` 再换上。以后你给她选了别的形象（页面、右键菜单、导入），都记成她的。
- **没做的**：两个人物同时出现；各人各一套素材库。

## 13. 四个地方，各有各的开关（0.8.0）

她出现在四个地方：**壁纸里**、**浮在桌面上**、**dsh 网页里**、**对话框上的小头像**。在「住在哪儿」里各有一个开关，另外还有菜单栏（托盘）图标的开关。

- **壁纸里 + 浮在桌面上**：以前是二选一（一个窗口，三种模式）。现在两个都开时是两个窗口：场景在壁纸位置，形象（或编排）里的宠物另开一个窗口浮在最上面。浮着的那个只负责显示、被拖、被碰和显示气泡；说话、听你说、回大脑的消息还是壁纸那个窗口的事（它不显示气泡）。形象里没有宠物时，两个都开也只有壁纸一个窗口；只有一个外形包时，它该在哪儿就在哪儿。
- **两个都关**：桌面上看不到她，但留一个不显示的窗口，她照样出声、照样听；快捷键叫出的对话小条照常。想让她完全安静，用"关掉她"。
- **dsh 网页里**：关 = 不在网页里出现；开 = 桌面程序没运行时出现（另有一个小开关："桌面上有她时，网页里也显示"）。
- **对话框上的小头像**：现在是独立的一处，不管她在不在网页里浮着都可以有。点它开对话小条。
- **菜单栏上的「她」**：可以关。关了以后右键她是同一个菜单；设置都在 dsh 里。
- **存在哪儿**：`<home>/places.json`（大脑记着你要的），桌面的两处、托盘、按住说话同时记在身体的 `body-settings.json`。身体连上时大脑在 welcome 的 `config` 里带上（`places`、`tray`、`holdKey`），身体在右键菜单里改了就回报 `body.prefs`。
- **老用户**：升级后第一次连上，按原来的模式算成"只开一处"，样子不变。新装的默认两处都开。
- **没验证**：Windows 上两个窗口同时开（壁纸层是另一套做法）。

## 14. 素材指南、三视图、抠掉背景（0.8.0）

- **一份数据，两处显示**：`src/core/material-guide.ts` 里一条一样素材：用在哪儿、用什么做（生图 / 图生视频）、尺寸、格式、时长、要求、怎么做（传哪张当参考、首尾帧用哪张）、提示词、做好后传到哪儿、放进编排的哪个场景。`docs/素材规格与提示词.md` 由它生成（`node scripts/make-material-doc.mjs`，测试会比对），页面「素材指南」显示的也是它。
- **页面**：顶上是四步（定人 → 三视图 → 其余从三视图派生 → 传上来摆好）和"你的人物"一栏：写一次自己的设定，下面每条提示词里的 `{人物}` 都换成它（记在这个浏览器里，每个人物各记各的）；默认是我们的鲸鱼娘。每条有"复制提示词"，还能复制整份文档。
- **我们不生成**：只给规格、要求和提示词，图和视频用户自己做（见记忆里的决定）。
- **三视图**：素材库多了一行「三视图」（`library/sheet/`），放定妆照、三视图、表情表。点"设为她的三视图"记在 `character.sheet`；只有一张时不用点。它显示在总览的"×× 的三视图"卡片里，旁边写着"头像、桌面、宠物都从它派生"。
- **抠掉背景**：视频工具出不了透明视频，所以头像、宠物素材上有"抠掉背景"：取画面顶上一条的颜色当背景色，有颜色的（绿幕、蓝幕）用 `chromakey`，白底灰底用 `colorkey`；视频另存成带透明的 WebM（VP9），图片另存成 PNG，原文件留着。要 ffmpeg 有 libvpx-vp9。
- **新的检查**：三视图不能是视频、宽不到 1200 提示；开机动画超过 8 秒提示。

## 16. 两个对话框怎么分工（0.8.0）

她有两个说话的地方：**头顶的气泡**（只读，跟着她）和**对话小条**（能打字、能按住说）。规则只有一条：**小条开着，对话就在小条里；小条关着，就在头顶。**

| 你怎么说的 | 她在哪儿回答 |
|---|---|
| 快捷键说一句、按住话筒、按住右 Option、一直在听 | 头顶气泡：上面一小行是她听到的，下面是她的回答；同时出声 |
| 在小条里打字，或按住小条里的话筒 | 小条里：你的话马上出现在右边，她在想时有三个点，回答一句一句出来；同时出声；头顶不再重复 |
| 她先开口、被你碰到 | 头顶气泡（小条正开着就在小条里） |

- **语音按钮在哪儿**：鼠标移到她身上，脚边浮出两个圆按钮：话筒（按住说，松开发出）和键盘（打开小条）。移开一会儿自己收起。小条里也有话筒。两个桌面窗口同时开时，按的是浮着的那个，听的是壁纸那个窗口的麦克风。
- **怎么做的**：小条开、关时告诉她的窗口（桌面：`bar-open`；网页：`__herGuest.bar`），窗口加上 `bar-open` 就不显示气泡和脚边按钮。小条直接听大脑的消息（`heard`、`state`、`speak.*`）把"正在说的"画出来，等读回来的对话里有了这一句就换成读回来的。
- **样子**：气泡和小条同一套：深色毛玻璃、细的强调色描边、圆角，都跟皮肤的三个变量（`--her-bar-bg/text/accent`）；小条里是左右两边的对话气泡、一个圆角输入条、话筒和发送两个圆按钮。
- 顺带修了：新版 dsh 把"运行环境"那条说明也留在会话里，小条和日记里把它当成了你说的话；现在不算了。

## 17. 0.8.1 的两处调整（2026-11-12）

**开关挪到总览。** 用户要的是"所见即所得"：五个开关做成一排，放在总览"她现在的样子"那张图的正下方——**壁纸里｜桌面上｜dsh中｜dsh对话框上｜菜单栏图标**（Windows 上叫托盘图标）。开了，图里对应的地方就出现（真的素材）；关了，那一样连同它的编号点和引线一起从图里消失，只留一行灰掉的文字"关着，在下面打开"，点它滚到开关。「住在哪儿」只剩桌面程序的安装和运行、她在网页里的样子（桌宠 / 背景、遮罩、朦胧），并有一行指到总览。

- "dsh中"开着就是真的在网页里：桌面程序在时也显示（原来那个"桌面上有她时，网页里也显示"的小开关并进来了，不再单独出现）。关了就是网页里不出现。
- 没有桌面程序的设备（VPS、手机打开的网页）上，壁纸里、桌面上、菜单栏图标三个是灰的。

**头顶气泡和对话小条不再同时画。** 原来图里 5 号（对话小条）和 7 号（头顶气泡）同时出现，和"小条开着时头顶不重复"的规则对不上，看起来像两处都在回答。现在合成一个 **5 号"她的回答"**，图的右上角有"说话时 / 打字时"切换：

- **说话时**：只画头顶气泡（上面一小行是她听到的，下面是回答）。气泡跟着她在哪儿：桌面上开着就在桌宠头顶；只开壁纸就在壁纸场景里；桌面两处都关就在 dsh 中的她头顶；哪儿都没有她，就只出声，文字这样写。

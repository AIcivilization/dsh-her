# M4 记录：内置记忆（另附：关思考提速的实测）

> 2026-10-29，Apple M1 Pro，macOS 27.2，DSH 0.2.1-rc.3（`her-dev`），模型 WorkBuddy DeepSeek-V4.1-Flash。

## 先做的小事：关掉思考能提速吗？—— 效果很有限

用 6 段合成的"你说的话"注入身体，测从你说完到她开口的时间：

| 思考强度 | 6 轮（毫秒） | 中位数 |
|---|---|---|
| 默认（high） | 2883 / 2361 / 2545 / 2191 / 2709 / 2697 | 约 2.6 秒 |
| `low` | 2461 / 2405 / 2833 / 2229 / 3066 / 2464 | 约 2.46 秒 |
| `off` | **会话卡死**：不报错，也不开始回答 | — |

**结论**：
- 瓶颈是模型服务返回第一个字的时间（约 1.6 秒），不是思考。`low` 只快了约 0.1 秒，回答质量看不出差别。
- 测试 profile 保持 `low`；插件默认值不变，仍用模型路由自己的默认值。
- `off` 不能用，而且出问题时完全静默。所以加了**看门狗**：你说话后 20 秒还没开始回答，就在气泡里提示"我好像卡住了"，并把会话事件记进日志。

## M4 做了什么

**存储**（`src/memory/store.ts`，放在 `<home>/characters/<cid>/memory/`，都是纯文本，可以直接打开）
- `facts.json`：关于你的事实。
  - 她用 `remember` 记的，直接确认。
  - 每天整理时发现的，先作为候选，7 天后自动确认。
  - 涉及健康、钱、证件、他人隐私的标为敏感，**永远不会自动确认**。除了模型自己的判断，还有一份关键词兜底。
- `episodes.jsonl`：事件。带日期的事，在**当天和前一天**会放进她的提示词里。
- `diary/<日期>.md`：她的日记，每天一篇。
- 读写都对"文件夹被手动删了"有防护，会自动重建。

**检索**（`src/memory/search.ts`）：中文按二字词切分，BM25 打分，新的记忆权重略高（60 天减半）。不用向量检索。

**她的工具**（只在她的会话里注册，用 dsh 原生的工具格式）
- `remember`：记事实或事件。事件可以带日期，她会把"下周三"换算成具体日期。
- `recall`：按话题查记忆。
- `forget`：按 `recall` 查到的编号删除。提示词要求她先跟你确认是哪一条。

**她的提示词**（每次请求模型时重新生成）
- 新增"记忆"一节：什么时候记、什么时候查、怎么忘。
- 新增"关于对方"一节：已确认的事实、最近两天的日记、这两天有日子的事。
- 新增"现在"：日期、星期、时段。只精确到时段（早上、晚上……），不到分钟，否则提示词每分钟都变，模型服务的缓存会失效。
- 任何一段生成出错时只跳过那一段。实测中发现，生成系统提示词时只要抛错，她这一轮就会**无声无息地不回答**。

**每天整理**（`src/memory/digest.ts` + 插件）
- 触发时机：你最后一次说话 30 分钟后，或者每天 23:30 以后，每天一次。dsh 重启后，会补整理昨天。
- 做法：从她的 dsh 会话里读出当天的对话（不包括"被打断"之类的备注和表演标记），用 `ctx.llm` 单独调一次模型（不进她的会话），写出日记、候选事实和事件。
- 已知的事实和事件都会告诉模型，存的时候也会去重：同一天、内容高度重合的事件只保留一条。

**忘记**：删除一条记忆时，日记里明显在说同一件事的句子也一起删掉，否则过两天它会通过"最近的日记"又回到她的提示词里。

**管理命令**（"她记得的事"页面放到 M5，和"她"页面一起做）

| 命令 | 作用 |
|---|---|
| `/her 记忆` | 列出全部记忆和编号 |
| `/her 确认 f3` | 确认一条候选事实 |
| `/her 忘掉 f3 e2` | 删除 |
| `/her 整理` | 立即整理今天 |
| `/her 导出记忆` | 导出一个 Markdown 文件 |

## 测试中发现并改掉的问题

1. 思考强度 `off` 会让会话静默卡死 → 加看门狗。
2. 生成系统提示词时抛错会让她静默不答 → 每一段单独兜底；记忆读写对目录缺失做防护。
3. 每天整理会重复记同一个事件 → 把已知事件告诉模型，并在存的时候去重。
4. 删掉的事会通过日记"回来" → 删除时一并清理日记里的相关句子。

## 已知的局限

- 她偶尔会添油加醋（比如把"橘猫"说成"胖橘"）。记忆里存的是原话，但她转述时会润色。
- 关于你的人称：提示词和整理都按"他"来写，因为示例人设是这么写的。向导（M5）应该让你选称呼和人称。
- "她记得的事"页面还没有，目前只能用命令和直接看文件，M5 一起做。
- Windows 没测（只涉及纯文件读写，风险低）。

# 设计：Ming 本地声音（2026-10-31，已实现）

> 背景和实测见 [Ming语音调研.md](Ming语音调研.md)。§8 的几件事已经定了（按建议），§11 是实现后的实测。

## 0. 一句话

在 Edge、百炼之外，加第三种声音来源：**本机 Ming**。
- 离线、免费、能表达情绪，也能用一句话描述出"她自己的声音"。
- 只给 Apple 芯片的 Mac，要用户点一下才装。
- 第一次下载约 2 GB，开着时占约 2 GB 内存。
- 不当默认，默认还是 Edge。

## 1. 用户看到的

在「她」页面 → 设置 → 声音：

1. 声音来源多一组「**本机 Ming**（离线、免费、能表达情绪；只支持 Apple 芯片，下载约 2 GB，占用约 2 GB 内存）」。
   - Intel Mac、Windows 上这一组显示成灰的，写明原因。
   - 内存 8 GB 的 Mac 能装，但会提示"可能会卡"。
2. 没装时只有一个按钮"安装本机声音"。点了以后：
   - 显示进度：装运行环境 → 下载模型 → 加载 → 试说一句；
   - 装好后自动念一句试听。
3. 装好后能选的声音有两种：
   - **内置声音**：6 个适合她的成年女声：灵风信、灵雨汐、灵梦、灵恬、灵小汐、灵小芸（名字后面写一句特点，和 Edge 的列表一样）。灵婉在官方声音表里标的是少女，不放。
   - **我的声音**：两个按钮「设计一个声音」「克隆一个声音」做出来的，见 §4。
4. 多两个选项：
   - "情绪"开关（默认开）：她开心、难过时，声音跟着变。
   - "速度优先 / 音质优先"（默认值等你听完试听再定，见 §8）。
5. 一个"卸载本机声音"按钮：删掉环境和模型，空出约 2 GB。

**换成 Ming 的声音以后**，原来的储备台词是旧声音录的。按[语音方案](语音方案.md) §4 的规矩，会提示"要重新生成吗"。

## 2. 安装（和 Edge 的 uv 做法一样）

- **Python 环境**：用已经有的 uv（固定版本、校验过）建 `<home>/ming/env`，Python 3.12。
  - 装 `mlx-audio` 时**按一份锁定文件装**：仓库里放 `python/ming-requirements.txt`，用 `uv pip compile --generate-hashes` 生成，每个包都固定版本和校验值。
  - mlx-audio 0.6.0 及以前会念错字，只有锁定的版本测过。
  - 装完删掉 uv 的下载缓存（实测缓存有 459 MB）。
- **模型**：`mlx-community/Ming-3.0-tts-0.5B-8bit`，**固定到某一次提交**，下载后按文件核对 SHA-256，放到 `<home>/ming/model`。
  - 中国大陆访问 Hugging Face 可能很慢，见 §8 第 4 条。
- **卸载**：删掉 `<home>/ming` 整个文件夹。不往别处写任何东西，也不动系统。
- **安装失败**：保留已经下好的部分，下次接着下。页面上写明是哪一步失败的。

## 3. 运行：一个常驻的小进程

- 仓库里放一个几十行的 Python 脚本 `python/ming_worker.py`，由插件用 `<home>/ming/env` 的 Python 启动（`-I`）。
- 通信方式：stdin 和 stdout 一行一个 JSON。
  - 请求：`{"id", "text", "voice" 或 "ref"(参考录音和它的文字), "emotion"?, "steps"?}`。
  - 回复：`{"id", "ok", "pcm16"(base64), "sampleRate": 44100, "ms"}`。
  - TS 这边包成 WAV，和 CosyVoice 一样。
- 一次只合成一句。语音队列会同时要 3 句，进程里排队就行，因为显卡本来也是一次跑一句。
- **加载和预热**：选了 Ming、或者身体连上时启动，加载完先空念一句"嗯。"（实测加载后的第一句要 4.9 秒，以后 1.5–3 秒）。
- **省内存**：长时间不说话就把进程停掉。
  - 你一开口（已有的 `warm()`，在识别你说的话的同时）就重新启动。
  - 重启加预热要 8 秒左右，所以"多久算长时间"见 §8 第 3 条。
- **进程挂了**：自动重启一次。再挂就把状态标成"出错"，处理方式见 §8 第 2 条。
- 新加的代码放在 `voice/ming.ts`（和 `edge.ts`、`cosyvoice.ts` 并列），`core/voices.ts` 里多一个服务 `ming`。

## 4. "我的声音"：设计一次，以后用克隆固定下来

同一句描述，每次设计出来的声音都有点不一样（实测两次就不同），所以不能每句话都用描述来合成。流程是：

1. 填一句描述。默认用形象工坊角色卡里的年龄、气质拼出来，比如"二十多岁的年轻女性，声音温柔甜美、略带慵懒"，可以改。
2. 点"生成 3 个试试"：用同一句固定的试听句各生成一次，可以分别播放。
3. 选中一个，起个名字，保存成 `<home>/voices/ming/<id>.wav` 加 `<id>.json`（描述、试听句的文字、创建时间）。
4. 以后她说话都用**克隆**：参考录音加它的文字。实测克隆出来的字都对，情绪也能叠加上去。

也可以**用一段录音克隆**：上传一段 5–15 秒的录音，并填上它说的话。
- 必须勾选"这是我本人的声音，或者我有授权"。
- 录音只放在本机，不上传到任何地方。
- 和外形一样：不做明星或其他真人的声音。

## 5. 情绪和小动作

- **情绪**：大脑已经会在每句话上标情绪（〔开心〕〔难过〕…，见 `core/cues.ts`），合成时把它一起带上：

  | 她的情绪 | 自带情绪版本的内置声音（灵风信、灵雨汐） | 其他内置声音、我的声音 |
  |---|---|---|
  | 开心 | `灵风信_高兴` | `emotion: 高兴` |
  | 难过 | `_悲伤` | `悲伤` |
  | 生气 | `_生气` | `生气` |
  | 惊讶 | `_惊讶`（有的话） | `惊讶` |
  | 害羞、嘟嘴、困、其他 | `_中性` | 不加 |

  - 情绪要算进短句缓存的 key 里。
  - "情绪"开关关掉，就一律用中性。
- **叹气、笑**：Ming 认识 `[Sigh]`、`[Laughter]`、`[Breathing]`、`[Uhm]` 等标记。
  - 只有用 Ming 时，才在她的提示词里多教两个标签〔叹气〕〔笑〕（每次回复最多一个），合成前换成对应的标记。
  - 字幕上照样不显示。
  - 实测叹气会盖住紧挨着的那个字，所以把标记放在句首或句末，不放在句子中间。

## 6. 数字和符号先念成汉字

MLX 版没有移植文字规范化，实测"2个小时"念成了"二个小时"。在 `core/` 里加一个 `spokenNumbers()`，只在 Ming 合成前用：

- `2个`、`2位`、`2点` 念成"两"；`3点15分` 念成"三点十五分"；
- `2026年` 一位一位读成"二零二六年"；电话号码、验证码这种长串数字也一位一位读；
- 百分比 `30%` 念成"百分之三十"；小数 `1.5` 念成"一点五"；
- `~` 念成"到"、`℃` 念成"度"，常见的几个符号就够了。

这个函数有完整的单元测试，测试用例就是上面这些。

## 7. 速度

- 实测在 M1 Pro 上，12 个字 1.5 秒，25 个字 2.3–3.4 秒，和 Edge（约 2.5 秒）差不多。
- 语音队列会提前合成后面的句子，所以真正要等的只有每次回复的第一句。
- **第一句太长时拆开**：只在用 Ming 时，如果一次回复的第一句超过 24 个字，就在第一个逗号处拆成两句。
  - 这样前半句 1.5 秒左右就能开口。
  - 字幕照样连着显示。
- 不用 mlx-audio 的"分段输出"（`stream=True`）。它只是按 24 字切开，效果和上面一样，而且实测切开的地方识别出了一处错。

## 8. 定下来的（2026-10-31，按建议）

1. **默认用哪个声音、默认速度还是音质**：听完试听再定。
   - 速度优先是 5 步，25 个字约 1.7 秒；音质优先是 10 步，约 2.9 秒。
   - 我的建议是先默认 10 步，你觉得慢再改。
2. **Ming 出错或还没装好时怎么办**：
   - (a) 这一句只显示文字；
   - (b) 临时用 Edge 念，声音会突然变。
   - 我倾向 (a)，加一个提示"本机声音出错了，点这里重启"。
3. **多久不说话就停掉进程，空出 2 GB 内存**：
   - 我建议 30 分钟；
   - 内存 16 GB 及以下的 Mac 改成 10 分钟；
   - 可以设成"一直开着"。
4. **大陆下载模型慢**：
   - (a) 只从 Hugging Face 下；
   - (b) 先试 Hugging Face，太慢就从 ModelScope 下官方原版模型，在本机转成 MLX 8 位格式（多下约 1 GB，多等几分钟，要再测一次）；
   - (c) 我们自己把转好的模型挂在 GitHub Release 上。模型是 MIT 许可，可以这么做，但这不算"代码"：它只放进 Release 附件，不进 git 仓库，和身体程序一样。

   我倾向 (c)，最省心。
5. **要不要 tiny 版**（MoE，内存更大）：建议先不要，0.5B 实测已经够准了。

结果：默认 10 步（设置里能换成速度优先）；出错只显示文字并给"重启"按钮；不说话 10 分钟（16 GB 及以下）或 30 分钟后停；模型放在 GitHub Release `ming-model-1`（标成预发布，不影响身体的 latest），下不动再从 Hugging Face 下；不做 tiny。

## 9. 分几步做

| 步 | 内容 | 做完能验证什么 |
|---|---|---|
| 1 | 锁定文件、安装、卸载、常驻进程、内置声音、设置页里能选能试听 | 在 her-dev 里换成灵风信，聊一轮。记下每次回复第一句要等多久 |
| 2 | 情绪映射、〔叹气〕〔笑〕、数字念法、第一句拆开 | 单元测试；聊天时开心、难过的句子听得出差别 |
| 3 | 设计我的声音、用录音克隆 | 设计 3 个、选一个，重启后还是同一个声音 |
| 4 | 不说话就停掉进程、出错后重启、内存小的 Mac 的提示 | 停掉后一开口能接上；把进程杀掉能自己恢复 |

每一步做完都在 her-dev 里实测，测完写进 `docs/语音方案.md`。

## 10. 不做的

- Windows、Intel Mac：已经用 audio.cpp 版做了（2026-11-13），见 [Ming跨平台.md](Ming跨平台.md)。
- 真正的边合成边播放（流式）：Ming 是整句合成，做不到；第一句拆开已经够用。
- 识别仍然用 SenseVoice，Ming 只负责说话。

## 11. 实现和实测（2026-10-31，M1 Pro，her-dev）

**代码**

| 文件 | 做什么 |
|---|---|
| `python/ming-requirements.in`、`.txt` | mlx-audio 0.6.3 和它依赖的 38 个包，固定版本和校验值。mlx 要 macOS 14 以上 |
| `python/ming_worker.py` | 常驻进程：加载模型并预热；之后一行一个 JSON 收发句子 |
| `src/voice/ming-model.ts` | 模型版本和 12 个文件的大小、SHA-256；先从 GitHub Release 下，失败再从 Hugging Face 下 |
| `src/voice/ming.ts` | 安装、卸载、启动、一句一句排队、不说话就停、连续出错两次就停下等重启 |
| `src/voice/ming-voices.ts` | "我的声音"（设计的、克隆的）、试听草稿、设置；把上传的录音转成 44.1 kHz 并去掉首尾静音 |
| `src/voice/uv.ts` | 从 Edge 那里拿出来的 uv 下载和运行，两边共用 |
| `src/core/spoken-numbers.ts` | 数字念法（§6） |
| `src/core/sounds.ts` | 〔叹气〕〔笑〕（§5） |
| `src/client/MingVoice.tsx` | 设置 → 声音里的"本机 Ming"：安装、选声音、设计、克隆、设置、卸载 |

第一句拆开（§7）不用新做：分句时第一句本来就会在 8 个字之后的第一个逗号处切开。

**实测**

| 项 | 结果 |
|---|---|
| 在页面上点"安装本机声音" | 约 3 分 40 秒装好，占 1.9 GB；模型从 GitHub Release 下载，校验都对 |
| 第一次试听（包含加载和预热） | 9.7 秒；之后一句 2.4–2.6 秒 |
| 数字 | 试听"离开会还有2个小时，现在是3点15分，涨了30%"，识别出来是"两个小时……三点十五分……百分之三十" |
| 克隆 | 上传录音后自动识别出文字；不勾"本人或有授权"就不让保存；保存后用它试听 2.4 秒 |
| 设计 | 一次生成 3 个，共 9.3 秒；留下一个后用它说话正常 |
| 聊天（灵风信） | 她自己用了〔笑〕；第一句文字出来后 1.4 秒开口（从发出消息算 7.8 秒，其中大模型 6.5 秒） |
| 单元测试 | 110 个通过（新加：数字念法、叹气和笑、情绪对应、我的声音、平台判断） |

还没测：
- 不说话停掉以后，一开口重新启动；
- 进程被杀掉以后能自己恢复；
- 内存 8 GB 的 Mac；
- 用手机"语音备忘录"录的 m4a 实际上传一次（代码用 macOS 自带的 afconvert 转换）。

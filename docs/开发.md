# 开发

设计和计划都在这个 `docs/` 文件夹里，从 [P1开发计划.md](P1开发计划.md) 看起；每个阶段的记录是 `M0验证记录.md` 到 `M6记录.md`。

## 组成

- **大脑**（仓库根目录，dsh 插件）：她在 dsh 里的专属会话"她 · 名字"、语音（本地识别 + 云端合成）、身体协议服务（`ws://127.0.0.1:38100` 起）。
- **身体**（`body/`，Electron 桌面程序）：她的形象、字幕气泡、对话小条、三种窗口模式。

两者之间的协议见 [身体协议.md](身体协议.md)。

## 构建和测试

```bash
npm install
npm test
npm run build
```

身体：

```bash
cd body
npm install
npm run build
```

打成一个可以分发的身体程序（mac；输出到 `release/`：zip 和 `body-latest.json`，传到 GitHub Release 后，插件会从 `body.releases` 下载安装、自动更新）：

```bash
cd body
npm run package
```

## 测试用的 profile

在一个单独的测试 profile 里运行（数据放在 `~/.dsh-her-dev`，不碰正式的 `~/.dsh-her`）：

```bash
dsh plugin --profile her-dev add link:/path/to/dsh-her
```

profile 的 `cordis.patch.yml`：

```yaml
- id: dsh-her
  name: dsh-her
  config:
    home: ~/.dsh-her-dev
    body:
      launch: auto          # dsh 启动 3 秒后若没有身体连上，就拉起 body/
      pack: ''              # 外形包目录；空 = 身体默认（~/dsh-her-dev-assets/bg2-stacked）
```

```bash
dsh --profile her-dev --no-open --port 3191
```

## 声音

默认用微软 Edge 的声音（通过开源工具 edge-tts，免费，要联网）；找不到已装好的 edge-tts 时会自动装进 `$DSH_HER_HOME/edge-tts`。阿里云百炼 CosyVoice 的 key 放进 mac 钥匙串（或环境变量 `DASHSCOPE_API_KEY`）：

```bash
security add-generic-password -a dsh-her -s dsh-her-dashscope -w
```

本地语音识别模型（约 170 MB，下载到 `$DSH_HER_HOME/models`），以及测速和各音色试听样本：

```bash
DSH_HER_HOME=~/.dsh-her-dev npm run voice:models
DSH_HER_HOME=~/.dsh-her-dev npm run voice:bench
```

## 素材

导入外形包（按 [素材生成提示词.md](素材生成提示词.md) 命名的一个文件夹）：

```bash
node body/scripts/import-pack.ts ~/我的角色 --packs ~/.dsh-her/packs --name 名字
```

合成测试包（色块小人，绿幕；加 `--scene` 是带空场景图的房间）：

```bash
node body/scripts/make-test-pack.mjs ~/dsh-her-dev-assets/test-doll-src
```

开发用素材都放在 `~/dsh-her-dev-assets/`，**不进仓库**。第三方演示素材由 `body/scripts/make-dev-pack.mjs` 转换。

## 发布

1. 根目录和 `body/` 都升版本号：`npm version X --no-git-tag-version`。
2. `cd body && npm run package`，解开 zip 跑 `Contents/MacOS/Electron --smoke`。
3. 提交、推送，等 CI 全过；打标签 `vX` 并推送。
4. `gh release create vX --draft`，带上 mac 的 zip 和 `body-latest.json`；`gh workflow run release-windows.yml -f tag=vX` 打 Windows 身体。
5. 下载 Release 核对 `body-latest.json` 里的大小和校验值，再 `gh release edit vX --draft=false --latest`。
6. `npm publish --access public --otp=<验证码>`。

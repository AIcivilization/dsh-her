# 素材规格与提示词

> 这份文档由 `src/core/material-guide.ts` 生成（`node scripts/make-material-doc.mjs`），和 dsh 里「她 → 素材指南」页面是同一份内容。在那个页面里可以把人物设定换成你自己的，每条提示词旁边有复制按钮。

她的样子都是你自己做的图片和视频：我们不替你生成，只告诉你**要做哪些、多大、有什么要求**，并给出可以直接复制的提示词。把提示词粘到你常用的工具里（生图：Gemini、ChatGPT、即梦等；图生视频：可灵、即梦、海螺、Vidu 等，要支持**首尾帧**），做好后传到 dsh 的「她 → 素材库」。

## 怎么用这份文档

1. **先定人**：做「定妆照」，多抽几次，挑最满意的一张。
2. **再做三视图**：正面、侧面、背面。传到 素材库 → 三视图，它会显示在总览里。
3. **其余全部从三视图派生**：做任何一张图，都把三视图传给工具当参考图；做任何一段视频，都先有一张图，再用它当首帧和尾帧。这样她在头像、桌面、桌宠里是同一个人。
4. **传到素材库，在编排里摆好**：每条下面写了传到哪一行、放进编排的哪个场景。

不用一次做完。最少只要：**头像·定格图**一张、**宠物·站姿图**一张（或**桌面·场景图**一张），她就能出现；其余的想到再加。

## 每一段视频都要遵守

- 固定机位：不推、不拉、不摇、不变焦、不切镜头。
- 首帧和尾帧用同一张图：这样循环播放时接得上，看不出断点。
- 画面里不要任何字：没有字幕、水印、Logo、界面元素（字幕由程序实时显示）。
- 不要声音：她的声音由程序实时合成。
- 同一个人、同一套衣服；换装就是另一组素材，从新的定妆照做起。
- 导出 MP4（H.264）。文件别太大：头像 5 MB 以内，宠物 20 MB 以内，桌面 40 MB 以内为好。

## 透明背景怎么来

宠物（和头像、开机动画，如果想要）需要透明背景，而视频工具一般出不了透明视频。做法：

1. 生成时用**纯绿色背景**（提示词里已经写了 `#00B140`），人物身上不要有绿色。
2. 传到素材库后，在那个素材上点**「抠掉背景」**：程序用 ffmpeg 把背景色去掉，生成一个带透明的 WebM（原文件留着）。
3. 抠得不干净（边上一圈绿、身上缺了一块）：多半是背景不均匀或衣服上有相近的颜色，换一次生成，或把背景换成纯蓝色再试。

## 二、头像（对话框上的小头像）

坐在 dsh 对话框上沿的她，正方形。不同的时候换不同的一段：发呆、说话、听你说、想事情、被摸头。

### 头像·定格图

- **用在哪儿**：dsh 对话框上沿的小头像（约 80×80 像素显示）；也是下面每段头像视频的首尾帧。
- **用什么做**：生图
- **尺寸**：512×512（正方形 1:1）
- **格式**：PNG（透明背景最好）；也可以用 SVG
- **要求**：
  - Q 版或胸像，头大一点，小尺寸下看得清脸。
  - 人物坐着或趴着，身体下沿平齐画面底边：像坐在对话框上。
  - 背景透明，或者单一的纯色。
- **怎么做**：把「三视图」传给工具当参考图。工具不能出透明背景时，用纯绿色背景，传到素材库后点「抠掉背景」。
- **做好后**：素材库 → 头像。 然后：编排 → 头像 → 初始。

提示词（直接复制）：

```
这是为deepseek-harness设计鲸鱼娘的角色之一，要求：
参考图是这个角色的三视图。人物必须和参考图是同一个人：同样的发型、发色、五官、服装和配色，不要改动。

画这个角色的 Q 版小头像：两头身，坐着，双手托腮，看向镜头，微笑。身体下沿和画面底边平齐，像坐在一块板子的边上。
正方形 1:1，人物占满画面的八成。背景是纯绿色（#00B140），完全均匀，没有地面、阴影、渐变和任何物体。
线条干净，色块清晰，小尺寸下也看得清。画面中没有任何文字、字幕、水印、Logo。
图片尺寸：512×512（正方形 1:1）；格式：PNG（透明背景最好）；也可以用 SVG。
```

- **用什么做**：图生视频
- **尺寸**：1280×800（16:10）或 1280×720
- **格式**：MP4；想要透明就用纯绿背景，传好后点「抠掉背景」
- **时长**：3–5 秒，不循环
- **要求**：
  - 有头有尾：从没有到出现，最后停在一个好看的姿势上。
  - 短：超过 5 秒就嫌长了。
- **怎么做**：尾帧传「宠物·站姿图」或「定妆照」（首帧可以不给，让工具自己发挥出场方式）。
- **做好后**：皮肤 → 开机动画 → 上传。

提示词（直接复制）：

```
这是为deepseek-harness设计鲸鱼娘的角色之一，要求：
尾帧是参考图。固定机位，镜头完全不动，不推拉、不摇移、不变焦、不切镜。

一朵浪花从画面下方涌上来，水花散开，她从浪花里轻快地跃出，转了半圈，稳稳落地，对着镜头挥手微笑，停在尾帧的姿势上。水花是透亮的海蓝色。
背景是纯绿色（#00B140），完全均匀，没有地面、阴影、渐变和任何物体。画面中没有任何文字、字幕、水印、Logo。不要声音。
视频尺寸：1280×800（16:10）或 1280×720；时长：3–5 秒，不循环。
```

## 六、皮肤背景图

### 皮肤背景图

- **用在哪儿**：dsh 整个界面的背景，文字都叠在上面。
- **用什么做**：生图
- **尺寸**：2560×1600（16:10）
- **格式**：JPG 或 WebP，1 MB 以内
- **要求**：
  - 细节要少、对比要低：上面要放很多字。

## 常见问题

- **循环接不上，有一下跳**：首帧和尾帧没用同一张图，或者工具没有严格按尾帧收。换支持首尾帧的工具，或者重抽。
- **人变了（脸、衣服不一样）**：没有传三视图当参考，或提示词里又描述了一遍外貌和参考图冲突。派生的图只写动作和场景，外貌交给参考图。
- **文件太大**：视频用工具导出时选 1080p 以内；传到素材库后会标出过大的文件。
- **想用真人或别的画风**：把「你的人物」那一段换掉即可，尺寸和规则都一样。真人的脸和声音要本人同意。
- **想整套导入成一个「形象」而不是用编排**：见 [形象工坊的素材说明](素材生成提示词.md)（锚点姿势、抠像、多场景）。

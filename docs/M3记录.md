# M3 记录：外形包与姿势图

> 2026-10-29，Apple M1 Pro，macOS 27.2，DSH 0.2.1-rc.3（`her-dev`），身体 Electron 44.7。
> 还没有真实素材，所以 M3 全程用合成的测试包验证：
> - "测试小人"（`body/scripts/make-test-pack.mjs`）：色块拼成的小人，站在绿幕上。
> - "测试小屋"（同一个脚本加 `--scene`）：同样的小人站在一个简单房间里，带空场景图，用来测场景包。
>
> 两套都按提示词文档的规则命名，每段的首尾帧严格对齐锚点。真实素材到了直接导入就行。

## 做了什么

**导入**（`body/main/pack/`，命令行 `node body/scripts/import-pack.ts <文件夹>`）
- `manifest.ts`：按文件名推断锚点、片段角色、过渡、储备台词，以及换装组合动作（`outfit_<衣服>` / `outfit_default`）。
- `media.ts`：只依赖 ffmpeg 一个程序（不需要 ffprobe），负责：
  - 读规格、取首尾帧、算 SSIM、识别绿幕。
  - 抠像后转成上下叠放的 H.264。
  - 生成点击遮罩：每秒 10 帧、宽 64 像素、每像素 1 字节。
- `import.ts`：检查最低要求、比对接缝、两段并行处理、写出 `pack.json` 和 `report.json`。失败时保留旧的外形包不动。

**播放**（`body/renderer/`）
- `director.ts`（导演，纯逻辑）：
  - 按状态挑片段；当前姿势没有对应状态的片段时，用待机代替。
  - 用最短路径走到目标姿势。
  - 处理动作、组合动作、情绪、储备台词，请求先到先做。
- `player.ts`（播放器）：
  - 首尾帧都对得上的，在最后一帧硬切，之前先把下一段预加载停在第一帧；对不上的交叉淡化 0.3 秒。
  - 有请求进来时，允许打断的循环片段立即切走。
  - 休息模式停在锚点姿势上。
- 点击判断改用导入时生成的遮罩；没有遮罩的外形包仍然读当前帧的透明度。
- 储备台词：播放对应片段时同时播放它的声音，气泡显示文字稿。
- 场景包：整个窗口就是场景，空场景图铺在身后，默认放进壁纸层。**不改系统壁纸**。

**大脑**
- 行内标记 `〔开心〕`、`〔动作:wave〕` 从句子里取出来（不念、不显示），作为提示随这句话发给身体，这句开始播放时做出来。外形包里没有的标记直接丢掉。
- 切句时不在 `〔…〕` 里面切开。
- 系统提示词的"表演"一节在每次请求模型时重新生成，只列出当前连着的身体能做的事。
- 新工具 `play_action`：用于换装、储备台词这类重动作，等身体回报做完才返回，最多等 90 秒。
- 回复里没有任何句子时，把这一轮的会话事件写进日志，方便排查。

## 测试中发现并改掉的问题

1. **动作被播了两遍**：播放器会在当前片段快结束时提前要下一段，导演又把同一个动作给了一次。改为已经排进播放的请求不再出新片段，等真正播完才结算。
2. **为了挥手而换衣服**：她穿着 JK 时要挥手，挥手片段只有原来那套衣服的，导演就让她出画面换回衣服再挥手。改为普通动作和情绪找路径时不经过"不在画面"；只有组合动作才允许离开画面。
3. **工具注册失败导致她完全不说话**：
   - 插件是用链接方式装进测试 profile 的，加载不到 dsh 的 `defineTool`，未转换的参数格式发到模型服务后，整个请求被拒（400）。
   - 改为直接用 dsh 原生的工具格式（纯 JSON Schema）。
   - 工具注册改成尽力而为：即使失败，她也照样能说话。
4. **SSIM 的写法**：`scale2ref` 在 ffmpeg 7 里比较静态图时没有输出，改成两张图都缩到 320×320 再比较。
5. **场景包分辨率**：原来和桌宠包一样限制在 720 宽，铺满屏幕太糊。场景包放宽到 1920。
6. **调用 `play_action` 之前不说话**：在表演说明里加了一句，要求她先说"好，等我一下"之类再去表演。效果还没复测。

## 还没做 / 没验证

- **真实素材**：一切都是用合成小人测的。真实 AI 视频的接缝分数一般在 0.85–0.98，0.95 的阈值合不合适，要等你的第一套素材来校准。
- **打断正在进行的组合动作**：比如换装途中你说话。过渡片段不允许打断，会走完；整体效果没有专门测过。
- **口型和动作同时进行**：说话片段和挥手片段二选一。说话时插入挥手，会先挥完手再回到说话片段。
- Windows 上没测。

# 演示视频脚本（约 3 分钟）

竞品靠 UP 主的长教程传播，最打动人的是她说出带人设的话。我们就拍他们没有的东西：**开口跟她说话，她像真人一样在你桌面上回应，你随时能打断她。**

开头 15 秒定生死，所以不从安装讲起。

| 时间 | 画面 | 旁白或字幕 |
|---|---|---|
| 0:00 | 普通的桌面。她在壁纸里低头画画。作者坐下，动了动鼠标 | 无旁白 |
| 0:05 | 她抬头，自己开口："你昨天那个面试，后来有消息吗？" | 字幕：她自己开口的 |
| 0:15 | 作者直接说话回答，没有按钮，没有打字 | 字幕：直接说话 |
| 0:25 | 她讲得正起劲，作者插话，她马上停下，接着作者的话说 | 字幕：随时能打断 |
| 0:40 | 用鼠标点她的头，她缩一下，来一句吐槽；连戳几下，她不耐烦 | 字幕：碰她也有反应，台词都按她的性格写 |
| 0:55 | 切到手机浏览器，打开同一个 dsh 网页，她也在，对话框上趴着她的小头像 | 字幕：手机上也在，Mac、Windows、VPS 都能用 |
| 1:10 | 切到 dsh 页面，她变成整个页面的背景，文字浮在上面 | 字幕：可以当背景 |
| 1:25 | 设置页贴入一张人设卡，点"拆成人设"，试聊一句，性格立刻变了 | 字幕：现成的人设卡贴进来就能用 |
| 1:45 | 形象工坊：传一张图，复制提示词，生成后传回去 | 字幕：换成你自己做的她 |
| 2:15 | 插件页搜 dsh-her，点安装，向导走完，她出现 | 字幕：不用命令行，几分钟装好 |
| 2:40 | 回到开头的桌面。作者起身离开，她说："去吧，我等你。" | 字幕：dsh-her，免费开源 |

## 拍之前要准备

- 一套拿得出手的形象（预设定下来之后）。真人的脸和声音要有本人同意；用 AI 生成的要说明。
- 一段提前聊过的记忆，让"面试"那句话是真的从记忆里来的。真实录屏，不要配音假装。
- 安静的环境，用耳机录，避免她的声音被当成你在说话。
